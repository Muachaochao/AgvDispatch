# 障碍等待与恢复安全回归

```powershell
dotnet run --project tools/ObstacleSafetySmokeTest
```

仅使用本机回环 Robokit 响应、临时 SQLite 与可控时间源，不连接现场 AGV 或 PLC。

- 精确识别 52200，Fatal 及同时存在的其他严重报警优先。
- 连续有效遥测计时、35 秒等待、明确恢复、重复/乱序/过期采样及断连重新计时。
- 受阻、未知状态或仅有 52200 时禁止追加新导航；已接受的原编号只读确认，不取消、不补发。
- 原车仍受阻时，即使 1110 同时返回 Completed 也不推进步骤、不释放原路权；另一台车可完成其原步骤。
- 受阻解除后沿用原任务完成证据自动推进；急停、Fatal、其他错误与坏质量仍阻止推进。

这些检查证明后台的等待及恢复逻辑，不证明车端会生成局部绕行轨迹，也不替代真实宽/窄通道、人员进入和实车恢复验收。
