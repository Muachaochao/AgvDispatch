# 3D包二维预览验证

从DispatchingSystem运行 `dotnet run --project tools/Smap3DPlaneSmokeTest`。真实包读取器、导入器、LocalMapEditorStore及WPF编辑器参与；生成两个明确合成容器，三维条目不是厂家有效Protobuf。无后台/实车调用。

结果、逐项CSV、格式/映射报告、实际截图和性能见docs/commissioning/evidence/20261015-smap3d-plane；用户可打开示例见docs/examples/robokit-3d-plane-preview。预算测试使用不高于生产上限的较小参数，不进行最大解压性能验收。
