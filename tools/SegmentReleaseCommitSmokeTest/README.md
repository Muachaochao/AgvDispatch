# 后台逐资源凭据消费

运行 `dotnet run --project tools/SegmentReleaseCommitSmokeTest`。35项，真实后台消费组件、唯一隔离SQLite、内存进度/核定包络、真实执行与恢复门；测试显式启用TrafficSegmentCommitOptions，生产注册值固定默认关闭，无设备连接。

请求只携ReceiptId/RequestId。消费重采两帧：首帧序号和时刻必须晚于原凭据末帧，控制器周期不变、进度不倒退、包络与配置不变，原任务/命令/地图/租约时期一致，原候选资源全部重新通过。旧缓存样本、离线、车体重入、重启、原租约变化、取消/换图/过期均拒绝。最新证据不兼容撤销原凭据，须重新签发。

门外设备读取，门内事务核验。按LeaseId/资源/归属/地图/AcquiredAt条件删除；逐资源审计、结果、Committed事件及交通SegmentReleased事件同事务。ReceiptId及RequestId唯一，租约时期审计唯一，提交结果与逐资源审计不可更新。末尾复核使用本事务已删除的原行重建原指纹，确认原行确已消失；不因本事务成功删除自己的租约而误判状态变化。

覆盖两资源释放与终点保持，完整审计/结果查询，重复、不同请求绑定、他车后来占用、新服务实例且开关关闭的历史结果重放，旧未提交会话拒绝，审计失败全回滚及原请求重试、事务末尾任务变化回滚、删除后取消回滚、并发请求一次提交一次重放。重放只读持久化结果，不触发任何新删除。

限制：没有Worker、公开IPC、角色授权流程或真实设备源。Pending/Committed查询不是现场安全放行授权。消耗开关未绑定现场配置且默认false；真实经过进度/控制器周期/命令归属/车体误差界未核定，不允许实际运行。未实现滚动分段下发或几何动态区域锁。证据见docs/commissioning/evidence/20261014-segment-commit。

消费同步更新TrafficRequest剩余资源及Held/Released状态，与解锁审计同事务；更新失败全回滚。末尾核验仅允许本事务声明并确实写入的诊断变化，其他身份/地图/原路线/任务仍严格核对。新增剩余显示及更新失败回滚验证。
