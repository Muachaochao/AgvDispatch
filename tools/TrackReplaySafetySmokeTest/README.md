运行 `dotnet run --project tools/TrackReplaySafetySmokeTest`，23项验证。

不是实车采集验收或完整ProfControl回放对标；仍未按真实采样间隔播放、拖动时间轴或倍速。当前播放每个定时周期前进一个点。
