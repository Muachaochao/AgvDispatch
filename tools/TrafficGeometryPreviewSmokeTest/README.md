# 几何区域锁只读冲突预检

运行 `dotnet run --project tools/TrafficGeometryPreviewSmokeTest`。45项纯内存验证，无数据库、连接或路权写入。

验证米制/地图版本/坐标系、有序方向正确的启用导航路段、核定整车最大载荷圆包络、定位误差与安全裕量。直线路段按胶囊模型距离判断交叠/接触；Bezier使用端点及控制点包围矩形，圆弧使用完整圆范围，扩张整车半径+误差+裕量。曲线结果标记保守候选，可能多报；不用有限采样宣称安全。

覆盖直线交叉、切触、明确间隙、包围盒重叠但胶囊分离、曲线范围/多报、坏/缺控制点、缺标定、非米制、错版本/坐标、未知绘图线、单向反向、无效坐标、超规模/比较/报告预算及取消。预算或报告达到上限时Complete=false，CanConcludeSeparated必须Available且Complete且无冲突。

默认Policy关闭，没有服务注册、地图显示或加/解锁；不是调度/实时避碰/空间索引或动态区域锁实现。未核验输入是否来自真实设备；只能在给定可信快照模型中判断空间交叠，不考虑运动时序、轨迹偏离或厂家实际路径。百段双路线10000对约1ms仅本机合成例，不是大型现场地图验收。
