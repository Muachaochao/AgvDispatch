# 倒料区实际退出几何判据回归

运行：`dotnet run --project tools/DumperExitSmokeTest`。

用合成米制地图检查两次独立、严格递增且新鲜的定位观测，核定的车辆报告参考点至整车/最大载荷圆包络，加定位误差上限与安全裕量后，是否在全部指定资源简单多边形边界之外。触边、相交、缺边界、身份/版本不符、无效质量、离线、阻塞、急停、未来/过期和未核定包络均拒绝；一次区内后一次区外不足，后续两次区外才可能通过。

这是纯函数判据，不依赖任务状态或“已发送返回命令”，不写PLC、不释放路权、不直接证明实车退出。调用方仍须核对有效地图版本与坐标绑定、本轮任务和时间门禁、持续占用及恢复状态，并在持久化事务内执行交接。定位误差上限必须来自现场核定，不能将置信度数值直接换算为误差半径。

`VerifyReturnRouteAfterExit` 另外检查原发送冻结返程：节点/边序列、方向和启用状态必须有效。进度仅从直线定位核定；只有未来Bezier完整控制凸包边界、圆弧完整圆包围盒与全部倒料资源包围盒分离，并留足整车、误差、裕量和允许路径偏离范围时，才接受区外曲线。当前定位只要可能处于任一曲线保守边界中就拒绝并等待后续区外直线定位，不以采样折线猜测通过。曲线可能触碰倒料区时保持占用，不降级到返箱后清位。

从当前定位允许偏差内的每个可能路径位置起，剩余整段路线都必须避开全部倒料边界，并把路线偏离上限额外加入扫掠圆半径。非相邻路径进度歧义、后续重入、载荷擦边或定位偏离原路都拒绝；相邻直线边公共端点只有所有可能进度都安全时才允许。保守曲线包围盒可能造成延后核定，这是明确的适用边界；现场应提供倒料区外直线退出段及核定的资源/载荷参数。

该回归不覆盖实际车辆定位精度、车体包络测量、无线通信质量或现场验收。
