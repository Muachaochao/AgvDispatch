# Web 地图编辑器工具补齐（2026-10-17）

本次补齐用户列出的三批编辑功能，入口为工程编辑工作台的「地图编辑」。沿用现有地图、资源、图层及编辑设置字段，不修改后端接口。

## 功能与使用

| 范围 | 已实现功能 |
| --- | --- |
| 画布交互 | 节点、区域、场景拖动；Ctrl / Shift 点选多选；空白拖框，Alt 可在对象上起框；所选组批量移动、删除；鼠标位置缩放，中键、右键或空格拖动平移 |
| 绘图 | 直线、三点圆弧、双控制点三次贝塞尔；曲线控制点拖动；资源多边形边界绘制；资源关联刷与解除关联；两点距离测量 |
| 批量编辑 | 节点及内部道路复制、复制并偏移；批量限速、单双向、启停；两节点合并；道路反向及按参数百分比拆分，保留曲线形状 |
| 对齐变换 | 左右上下对齐、水平与垂直居中、水平与垂直等距、顺逆时针 90°、左右与上下镜像 |
| 吸附 | 可配置间距的网格、网格吸附、节点吸附、对齐参考线；吸附选项独立开关 |
| 图层 | 新建、重命名、当前层、显示、锁定、可选、透明度、颜色、线宽、对象移层、删除并迁移对象 |
| 拓扑 | 按选择顺序自动连接、正交连接、闭合环路、失效与重复道路清理、同图层直线交叉和 T 形路口拆分 |
| 历史 | 撤销、重做、带名称的操作历史及回退；完整拖动或关联刷只记一步 |

圆弧依次点选两个端点和一个弧上点。贝塞尔依次点选两个端点和两个控制点。资源边界逐点绘制，Enter、双击或工具栏按钮完成；Backspace 删除最后一个待绘点。自交、多点共线等无效边界会被拒绝。

工具栏「批量 / 对齐 / 拓扑」「图层」「历史」切换右侧面板。拓扑连接按节点选择顺序执行；交叉拆分只处理同图层可编辑直线，曲线和不同图层交叉保持原状。清理保留孤立节点及具有不同通行属性的道路。

隐藏、锁定或禁止选择的图层不会被框选或修改；若节点操作还会修改受保护的关联道路等对象，整个操作会被拒绝。默认导航层保留，其他层删除时将对象迁移到可编辑层。

## 快捷键与保存范围

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 撤销 / 重做 |
| Ctrl+S | 保存当前方案到浏览器本地 |
| Ctrl+C / Ctrl+V / Ctrl+D | 编辑器内复制 / 粘贴 / 复制并偏移 |
| Ctrl+A | 全选当前编辑页可编辑对象 |
| Delete / Escape | 删除选择 / 取消未完成操作 |
| Space + 拖动 | 平移画布 |

快捷键在地图与场景页生效；输入框、下拉框和对话框内保留文本编辑行为。复制粘贴使用当前编辑器内存剪贴板，复制道路会带上端点并重建引用。复制节点的厂家站点绑定清空，原对象绑定保留，需为新节点重新确认绑定。

Ctrl+S 仅本地保存。现有后台草稿保存、发布及地图激活仍通过原有明确按钮执行。历史仅保留当前编辑会话，最多 100 步且受约 32MiB 快照预算限制，新编辑会清除重做分支。

## 实现与验证

`PlanningWorkbench.vue` 负责集成画布与原有方案流程；几何操作、交互状态和工具面板分别位于 `map-editing.ts`、`use-map-editor.ts`、`MapEditorPanels.vue`，便于独立验证与后续维护。兼容无显式图层的旧方案；图层与编辑设置随现有地图 JSON 保存。

在 `AgvDispatch.Web` 目录运行：

```powershell
npm.cmd test
npm.cmd run build
# 另一个终端先启动前端
npm.cmd run dev -- --port 5199
npm.cmd run test:editor-browser
```

浏览器检查使用已安装的 Edge / Chrome、独立临时用户目录及回环地址，不操作个人浏览器，不提交或发布后台地图。可用 `EDITOR_TEST_BROWSER` 指定浏览器可执行文件；测试地址配置见脚本。

本次验证：85 项单元测试通过，Vue / TypeScript 与 Vite 生产构建通过，26 项实际浏览器交互检查通过，无未捕获浏览器异常。覆盖拖动、撤销重做、多选、曲线及控制点、反向拆分、边界、测量、框选、复制删除、关联刷、图层锁定隐藏删除迁移与保存。桌面及笔记本尺寸截图和检查结果生成于 `AgvDispatch.Web/evidence/editor-interactions/`，按仓库规则不提交生成产物。

此验证使用合成地图；不代表实车地图、固件或现场验收已通过。生产构建仍有现有大体积 bundle 提示，不阻止构建。
