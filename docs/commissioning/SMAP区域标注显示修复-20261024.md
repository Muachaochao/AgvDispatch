# SMAP 区域标注显示修复（2026-10-24）

现场 ZM-test.smap 含 7 站点、12 条有向路径和 5 个 AreaDescription。此前解析器仅将 advancedAreaList 边界栅格化到本地底图，Web 工程编辑器不加载该底图，因而漏显区域和中文说明。

本次将区域作为 MapDefinition.areaAnnotations 保存，保留多边形、UTF-8 Base64 说明、颜色及源对象 JSON。厂家区域标注使用独立图层；Web 编辑器提供显示开关，文字放在区域上方以避开站点。运行图的 Web 投影与大屏也显示这些标注。描述区不生成交通资源、动作或业务站点用途；其他高级区域只作显示，未适配的厂家行为明确提示。

区域坐标使用与站点相同的预览平移，在 PrepareRobotWorldRuntime 中一起还原。规范化 JSON、草稿和版本差异保留区域；旧版本缺失该字段时不序列化空属性，避免改变已有定义指纹。

更新后须重新导入原 SMAP（或重新只读拉取车端地图），再加载到编辑稿；旧编辑稿没有区域数据，不能靠刷新补回。保存草稿、发布和切换仍由用户操作，不自动替换当前运行地图。

验证：后台单车模拟检查 83 项，前端测试 139 项；真实 ZM-test.smap 的 5 个区域逐顶点坐标核对及规范化 JSON 导入/导出通过。构建 Service、WebHost 和 Web；使用独立源码快照验证，保留工作区其他正在进行的改动。未下发导航、顶升、地图写入或切换命令。
