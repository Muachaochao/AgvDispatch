## 单次导航入口

Web 工程工具 → 单次导航测试（`/#/navigation-test`）。新接口均经主服务 Named Pipe 执行；Web 不直接连接车端。

候选包默认不启用此功能。显式运行 `Start-Navigation-Test.cmd AGV-01` 或启动器参数 `--navigation-test-vehicle AGV-01`，仅针对指定车辆启用单次导航及全局 AGV 动作许可。任务创建、自动派发、步骤、Outbox、新PLC握手仍强制关闭。普通启动入口继续关闭 AGV 动作；运行中不能静默切换测试模式或车辆。

须先完成厂家速度设置及区域确认。车辆停在起点，输入厂家站点编号，核验后勾选区域确认，再点击发送。核验/页面加载均不发送运动指令。

此入口按车端当前地图工作，不需要配置九步PLC业务任务，也不把编辑器预览图视为车端地图。只测试一条车端1303返回的直接相邻路径。正式业务调度的发布、激活、地图绑定、PLC及路权流程仍独立保留。

## 发送与异常处理

- 测试开关、全局AGV动作开关及明确关闭的业务执行开关均须满足；指定车辆必须启用采集，没有活动业务任务。
- 发送前重新读取1300地图身份、1022加载状态、1060控制权、1301站点、1303路线及1100/1110状态。控制权须明确未占用，且核验结束时仍未占用；不抢占厂家控制权。
- 定位置信度至少0.5，距车端起点坐标不超过0.25米；要求静止、未充电、无急停阻挡和严重报警，没有未结束或未知任务。速度沿用车端路径配置，本功能不写入速度参数。
- 使用一次性、30秒有效的核验令牌；提交时重新核验地图身份和状态，持有地图执行门禁。一次只允许一个未结束测试。
- 发送前将唯一任务编号、车辆、起终点、车端地图名/MD5、操作者和发送意图落盘并Flush。只发送一条3066记录，不携带取箱、顶升等operation，明确ret_code=0才标为接受。
- 回执丢失、超时、断线或后台重启不自动重发。查询始终使用持久化原任务编号；404、缺项、重复或未知状态均不算完成，不解锁新测试。
- 取消仅针对本记录的原任务编号发送3003，禁止无范围取消。收到取消应答后继续查询，终态且车辆静止才结束。协议取消不是物理急停。
