# 单次导航测试与 DegenerateBezier 导入修复

## 已修复

- Smap2DImportService 接受 DegenerateBezier，保留有序控制点、厂家站点映射及每条显式有向路径。与原导入一致，显示坐标保留可逆平移，节点和路径初始停用，不擅自开启正式调度。
- MapValidationService 允许同几何、恰好两条相反方向的单向边；同方向重复、双向边再叠加反向边仍报错。
- 现场提供的四点文件经过实际 WebHost → IPC → 导入器验证，得到4个站点、10条有向路径，结构校验0错误。原始现场文件不入库。

## 单次导航入口

Web 工程工具 → 单次导航测试（`/#/navigation-test`）。新接口均经主服务 Named Pipe 执行；Web 不直接连接车端。

候选包默认不启用此功能。显式运行 `Start-Navigation-Test.cmd AGV-01` 或启动器参数 `--navigation-test-vehicle AGV-01`，仅针对指定车辆启用单次导航及全局 AGV 动作许可。任务创建、自动派发、步骤、Outbox、新PLC握手仍强制关闭。普通启动入口继续关闭 AGV 动作；运行中不能静默切换测试模式或车辆。

须先完成厂家速度设置及区域确认。车辆停在起点，输入厂家站点编号，核验后勾选区域确认，再点击发送。核验/页面加载均不发送运动指令。

此入口按车端当前地图工作，不需要配置九步PLC业务任务，也不把编辑器预览图视为车端地图。只测试一条车端1303返回的直接相邻路径。正式业务调度的发布、激活、地图绑定、PLC及路权流程仍独立保留。

## 发送与异常处理

- 测试开关、全局AGV动作开关及明确关闭的业务执行开关均须满足；指定车辆必须启用采集，没有活动业务任务。
- 发送前重新读取1300地图身份、1022加载状态、1060控制权、1301站点、1303路线及1100/1110状态。控制权须明确未占用，且核验结束时仍未占用；不抢占厂家控制权。
- 定位置信度至少0.5，距车端起点坐标不超过0.25米；要求静止、未充电、无急停阻挡和严重报警，没有未结束或未知任务。速度沿用车端路径配置，本功能不写入速度参数。
- 使用一次性、30秒有效的核验令牌；提交时重新核验地图身份和状态，持有地图执行门禁。一次只允许一个未结束测试。
- 发送前将唯一任务编号、车辆、起终点、车端地图名/MD5、操作者和发送意图落盘并Flush。只发送一条3066记录，不携带取箱、顶升等operation，明确ret_code=0才标为接受。
- 回执丢失、超时、断线或后台重启不自动重发。查询始终使用持久化原任务编号；404、缺项、重复或未知状态均不算完成，不解锁新测试。
- 取消仅针对本记录的原任务编号发送3003，禁止无范围取消。收到取消应答后继续查询，终态且车辆静止才结束。协议取消不是物理急停。

## 现场1110包装兼容修复

真实RBK 3.4返回的1110列表位于 `task_status_package.task_status_list`。原单次导航门禁只检查外层，导致已完成历史任务被误报为列表未知。现同时支持直接列表和明确嵌套包装；包装错误、两份歧义列表、缺失列表、未知状态及状态1/2/3均继续阻塞。状态4/5/6/7允许通过空闲检查；历史任务编号为空只用于空闲判定，绝不作为本软件新任务的接受、完成或取消凭据。

补充回归后共39项通过，含嵌套包装贯穿下发、查询、取消及重启流程。现场更新后，通过实际浏览器点击只读核验按钮，LM1→LM2地图身份和路线均正常显示，未勾选现场确认、未发送导航。此前截图工具不可用的情况已解除，本次已取得并检查页面截图；这只证明页面和只读核验，不证明真车移动验收。

## RobotWorld运行图与现场激活

- `PrepareRobotWorldRuntime` 先要求逐站确认用途，完整恢复节点及曲线控制点到车端坐标；保留显式方向，启用节点与路径，重新进行运行图结构校验。存在未知节点或未转换路径时拒绝生成运行图。
- 单车测试准备工具：`dotnet run --project tools/SingleNavigationTestSmokeTest -- --prepare-runtime <原生smap> <输出json>`。此显式模式把站点用途设为测试停靠点，只生成文件，不保存后台、不激活、不发车；输出须继续与车端站点和现场用途核对。
- 首次激活从未提交且原运行图为空时，取消原失败切换不再要求在未使用目标预览图中停靠。数据库/运行图仍必须一致为空；任务、命令、步骤、路权、地图传输、在线新鲜状态、静止、急停阻挡、定位质量和PLC检查仍保留。原切换留存为取消记录，修正版另建关联明确的新切换。
- 仅地图绑定差异可在地图模式Running时持控制锁保存，仍要求权限、无活动任务、有效修订和绑定内容校验；任何设备端点、开关、协议等变化均不能走此分支。保存只影响下次启动，不更改活动绑定或清除执行恢复屏障。
- 现场四点文件已逐站与车端1301比对，四站均设为测试停靠点，发布并激活V2。旧失败切换已取消留痕，新切换已完成，启动后已加载核对后的地图绑定。实际大屏显示4节点/10道路/1辆可定位，车辆在LM1附近，定位Normal。原始现场文件、地图记录与截图不入库。
- 针对性检查43项、地图切换81项及通信配置回归通过。修复旧切换测试夹具遗漏的依赖与在线车辆返回，使真实Outbox门禁回归可执行。大屏截图验证通过。
