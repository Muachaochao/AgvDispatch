# 地图编辑器布局与工具说明

编辑器使用“顶部工具、中央画布、右侧可收起面板、底部状态”的组织方式。原先覆盖画布左侧的文件参数卡片已移除。

独立窗口的额外介绍横条已移除，窗口标题栏保留应用名称。绘图工具按钮至少 70 像素宽，标签使用 11 号字并跟随工具选中颜色；空间不足时工具区可横向滚动，不覆盖右侧吸附控制。属性面板不再重复显示属性/图层/模板标签栏，统一使用右侧入口。新建地图仅保留顶部按钮。

## 面板

- 地图配置：右侧“配置”打开。包含名称、说明、CAD底图、坐标单位及比例；导入与备份默认折叠。
- 对象属性：选择节点或路段后打开“属性”，查看编号、坐标、节点类型、限速、曲线控制点和交通资源。
- 图层：配置图层和对象可见性、画布尺寸、网格。隐藏不代表禁行，不删除对象。
- 模型：业务站点、等待点、充电点等站点模板。
- 同一个 280 像素右侧面板在配置与对象工具间切换，不同时堆叠。点击面板标题右侧箭头可收起整个面板；右侧 90 像素工具栏保留“图标＋名称”的配置、属性、图层、模板入口，便于再次打开。顶部重复的配置、属性、图层、模型、面板入口已移除。

## 绘图工具

选择/框选、平移、路径节点、业务站点、直线路段、圆弧、贝塞尔曲线、曲线控制柄、资源边界、边界顶点、资源绑定、测量位于顶部第二行。悬停查看各工具的使用说明；右键或 Esc 退出连续绘制。

地图选择、新建、撤销/重做、保存、校验发布位于顶部第一行。右侧“详细”是高级功能的统一入口，展开后选择高级工具、站点/路段数据、地图校验、CAD或安全切换等标签；再次点击收起。右侧“刷新”用于连接后台服务并重读地图，不直接连接现场PLC/AGV。底部不再放置操作按钮。顶部不再重复放置高级工具、对象表、地图分析、安全切换快捷按钮。安全切换原有确认及校验流程保留，不放在日常文件配置中。
