# CAD 底图清晰度与局部渲染

## 使用方式

地图编辑器的“CAD图层”区域提供清晰度、透明度和局部高清开关。

- 标准：2200 × 1400；高清：4096 × 2608（默认）；超清：6144 × 3909。
- 清晰度选择只影响下一次生成。选择后点击“重建底图”，已有缓存不会自动变清晰。
- 透明度范围 20%～100%；底图与局部高清合并后统一应用透明度。
- 开启局部高清后，放大、移动停止约 650 ms 后请求当前可视区域。请求期间和失败时保留全图底图。
- 总览仍使用轻量全图底图，局部高清仅用于地图编辑。节点、路段和路权区域保持独立矢量绘制。

图层筛选沿用地图项目配置；使用已整理的下方有效布局参考副本，可排除上方作废布局。不会删除或覆盖原始 DWG，不会自动切换已发布地图或修改标定。

## 分层和坐标

WPF 根据实际视口变换与屏幕 DPI 计算可见底图范围，将其转换为 CAD 世界坐标。后台返回局部 PNG 及其世界坐标边界，前端再映射回同一底图坐标系。Y 轴反向、标定及导航几何不随刷新改变。

`ICadDetailClient` → 独立只读 Named Pipe（原管道名加 `.cad-detail`）→ `ICadDetailService` → `ICadUnderlayService`。

高清渲染不占用普通状态、任务 API 的串行管道。独立管道仅接受高清查询，不允许发布等写操作。后台依据 MapId 查找 CAD 源文件和图层，不接受客户端指定任意源文件路径；同时校验底图版本、区域和分辨率。

渲染器缓存一个预处理 CAD 文档与实体边界。区域渲染固定世界坐标取景框，跳过框外实体。同一地图的新请求取消旧请求；前端另外校验请求版本，忽略迟到结果。

局部缓存目录为配置缓存路径下的 `cad-detail`；内存索引最多 24 项，磁盘保留最多 32 个本功能生成的 PNG。缓存键包含源文件时间、大小、图层、底图版本、区域及分辨率。不会清理其他目录。

地图项目新增可空的 UnderlayWidth / UnderlayHeight，随现有数据库初始化机制升级。旧记录为空时使用高清默认尺寸，重启后的底图任务沿用持久化尺寸。

## 性能和限制

本次实际 B07 图纸测试：首次全图约 72 秒，首次局部约 27 秒，预处理缓存后的局部约 7 秒；相同请求命中局部图片缓存后不再次渲染。耗时取决于机器、实体复杂度和范围，不是实时 CAD 绘图。

局部图仍是按视口重新生成的位图，而不是无限精度矢量 CAD。字体替代、曲线采样等可能与原生 CAD 有差别。正在执行的底层绘图不能立即中断；取消会使结果被丢弃。前端请求最多等待 3 分钟。

```powershell

```

验证覆盖：可见图层、块变换、固定坐标局部图片、源文件变化失效、区域与版本拒绝、缓存上限、请求取消、前端迟到结果、防止导航错位、真实 Windows 管道并发与拒绝写操作。编辑器普通测试 498 项，含离屏渲染测试 551 项通过；解决方案构建通过。现有 ImageSharp 包安全警告仍需独立处理。

发布更新只同步程序文件，保留发布目录的配置、数据与日志配置。PLC 通信/写入、AGV 通信/命令及自动调度仍关闭，本功能不启用现场运行。
