# 地图激活回执丢失与只读复核

当前快捷AGV/Robokit TCP主工程。此批只核对后台地图切换，不证明车端地图上传/载入、厂家MD5、坐标对齐或现场放行。

## 操作

地图管理激活前保存原切换编号、目标地图/版本和请求时间到当前浏览器站点的本地记录，并把ExpectedReleaseId随激活请求发给后台。通信异常、无效回执或后台拒绝都转入原编号只读复核，不把失败解释为未提交。刷新页面/重连仍保留记录；本地记录损坏不能静默覆盖。跨标签页变化更新保护。

待核对横幅→“只读复核原激活”。复核显示原持久化阶段、数据库活动图、运行图、本地内容SHA256和执行门。只读接口按原编号精确查询，不受最近30条历史截断；持久化信息在只读事务内读取，运行图由原控制门保护。

- 已观察提交：原记录AwaitingResume，数据库及运行图目标和本地内容一致；仍待人工核对，不重发激活。
- 仍观察原图：Draining且原指针一致；不是原请求从未到达或稍后不会到达的证明，禁止自动重试。
- 原记录未找到、目标身份不符、内容/阶段不一致：保持待核对，不能借其他切换或同名地图下结论。
- 关闭历史：仅说明原切换已结束，不证明当前允许派发。

只有新鲜、匹配原编号/目标且内容一致的已提交/关闭观察，才能人工结束本地待核对标记并转入原安全流程；不会自动激活或恢复派发，安全确认重新勾选。7秒过期、断连、数据源/地图上下文变化禁用旧结论。

仍观察到原图时，可在有效同编号观察下进入原安全切换手动取消原批次，后台照常核对原安全条件；不允许重复激活或直接放行。缺记录/不一致时应核对原后台、原数据库及持久化记录，页面不提供强制清除。

## 边界

新增View权限的ReviewMapActivation及POST /api/maps/activation-review；无通用管道透传。复核不初始化恢复账本、不写审计、不取消、不释放任何资源。CanStartNewWork只是门状态观察，不是操作许可。旧客户端不传ExpectedReleaseId仍兼容；本版Web始终绑定原编号，传了错误编号会被后台拒绝。

用户清除浏览器数据或更换浏览器会丢失本地意图；持久化切换记录仍在后台。必须按原切换核对，不能以本地标记不存在证明未激活。浏览器本地存储不是厂家幂等编号或独立服务端幂等账本。

## 验证

通过专用工具在私有Service/唯一管道/随机本机端口/新SQLite中验证：请求发送前丢失；提交后丢回执并中断Service；同库重启只读核对；旧编号拒绝与重复激活不再产生提交；迟到/过期观察和页面刷新保护。故障注入只在测试浏览器CDP和工具临时目录，不给生产程序增加断电/故障按钮。现场控制及上传继续关闭。
