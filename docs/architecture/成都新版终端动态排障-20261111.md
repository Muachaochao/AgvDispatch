## 发现与处理

1. 地图模板的definitionHash默认空字符串导致导入拒绝：现按规范化地图JSON生成本地SHA256；本地投影不冒充现场发布摘要。
2. 删除未经测绘的处置位后，检修软件引用WAIT-01被Station类型校验拒绝：允许已有Station/WaitingPoint，仍拒绝道路Waypoint。该引用不证明现场已具备应急安全点。
3. 八呼叫运行观察到多台满箱车停靠原工位后产生长绕行，AGV-01累计约280米。提前取箱量和候车策略仍需进一步优化，不能用加速掩盖实际吞吐。
4. 来料路线可预占倒料车返回共享口：倒料入口绑定首个返回交叉口资源，使其在入位前一并取得，出区后仍按原有车体通过证据释放，没有人工删路权。
5. 原返回线并入主道处距CNC-291停靠中心约0.31米，位于该站占道保护范围：仅加出口资源保护还不足以解除这一物理拓扑问题。改在下排主道南侧向东折，再从CNC-291/292间隙北上，保留交叉共享节点；未移动CNC或放宽停靠包络。
