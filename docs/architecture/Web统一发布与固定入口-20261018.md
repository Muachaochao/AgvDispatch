# Web统一发布与固定入口

2026-10-18。Web为操作界面，主Service为调度执行主体，WebHost作本机适配，WPF保留部分工程配置。没有替换Robokit TCP或PLC后台。

## 使用

本机完整包内先用Start-Latest-Web.cmd。它验证组件批次、检查端口、启动本版后台及Web、等待实际后台快照连通后打开浏览器。重复点击复用记录的本版进程；只有半套程序在运行或端口被其他程序占用时拒绝替换，按提示处理。Stop-Latest-Web.cmd只核对PID、启动时间和完整路径后停止本入口记录的进程，不按名称批量结束，不关闭浏览器。

入口使用自带运行时，CMD直接运行程序，不调用PowerShell脚本。当前是强制关闭PLC/AGV通信、写入、创建/派发、Outbox、步骤执行及新握手的开发联调入口；没有现场配置迁移和设备验收。不能通过这个入口现场开跑。分组件入口保留作工程排查，不能与一键入口混用。

浏览器默认连接真实后台；没有车辆、地图和任务时显示为空。点击顶部演示模式后显示明确的source=demo合成内容，不当作现场执行；退出演示清定时器并恢复后台模式。切入演示撤销提交状态，页面可见性变化不自动退出演示或连接后台。

工程顺序：联调检查→工程编辑→地图草稿保存→发布→地图管理→明确选择目标、安全收尾、输入精确ACTIVATE确认文字和独立核对依据→激活待放行→在安全切换中核对后人工放行。恢复中断的原任务收尾不是地图激活，不能用它代替激活。后台阶段可为文字枚举，前端同时兼容旧数字表示。

## 数据与版本

新完整包放独立目录，不覆盖其他目录的配置、点表、地图或数据库。浏览器本地方案按来源保存，端口变化可能看不到原列表，不代表数据被删除；本次本机固定入口继续使用5188。综合方案仍需导出备份，尚非完整服务端项目库。

release-manifest.json是初始完整包文件清单。运行后会新增Runtime会话、数据库或日志，因此应在首次运行前核对初始包，保留原包。批次标识用于发现混用，不是软件签名、厂家固件核定或现场放行。

## 复验

- npm test与生产构建：验证类型和前端模型。
- tools/WebAdapterSmokeTest --candidate-dir 完整包：复制真实Service、唯一管道、私有SQLite和回环端口，验证查询、地图保存发布/安全激活/放行、诊断与默认关闭入口。
- tools/Test-WebLocalLauncher.ps1：复制完整包，检查启动就绪、重复点击、精确进程身份、停止、占用端口拒绝；不打开个人浏览器、不连接现场。
- EDITOR_TEST_URL设为隔离Web地址，EDITOR_TEST_BACKEND_FLOW=1时运行前端test:editor-browser：独立浏览器用户目录，验证演示切换、编辑工具及已发布测试图激活待放行/人工放行。仅允许本机地址。

原ImageSharp依赖安全告警和Three.js大分块提示未在本批消除。完整验证结果按本机发布记录列明，不沿用旧候选测试来代表新源码。
