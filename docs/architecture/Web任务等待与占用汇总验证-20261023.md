## 本批结果

大屏当前任务和任务列表使用同一套只读等待解释。原业务阶段仍保留，例如“路权／候车位等待；业务阶段：取箱确认”，避免把等待误认为仍在做取箱动作。设备归属等待显示“倒料设备许可等待”，混合条件显示“多项条件等待”。这不替换任务状态机，也不代表已经拿到PLC入站许可。

仅在后台连接有效、快照与交通观察均在7秒窗口内、同地图版本、任务及车辆身份和业务阶段一致时显示。取消中、取消待核对、故障及终态保留原状态。断连、旧页任务、异图、时间异常或等待记录已结束时撤下等待覆盖。交通记录截断时标注观察范围；没有等待覆盖不等于确认无等待。

共享区域按“任务＋车辆”汇总租约，同任务两步骤持有同一资源显示“同车2条租约”，容量数字原样使用后台occupiedCount/capacity，不按行数重算。异任务同车依旧分开，避免隐藏异常归属。等待队列按资源、地图版本、任务和车辆汇总阻塞方，展开保留原步骤；任一原租约心跳过期则仍显示占用保留，定位须全部原记录通过原有同图检查。阻塞链原始明细不合并。

修复任务卡片在短窗口被flex压缩产生文字叠加的问题：卡片不收缩、编号换行、原因完整显示、面板可滚动。业务阶段环图继续按阶段计数并明确命名，候车等待不会被当作另一个任务重复计数。

## 使用方法

1. 大屏“当前任务”先看等待标签，再看下方业务阶段和具体原因；点击卡片仍进入原任务步骤。
2. 在“共享区域”查看后台容量，例如1/1；展开车辆行可见任务归属和租约条数。
3. 下滚到“交通等待队列”，展开“原占用任务／步骤”查看原始步骤编号；“阻塞链”继续显示各步骤的释放核验要求。
4. 面板内容多时在面板内滚动，页面滚动进入完整等待队列；任务列表显示同一等待解释。

## 候车位提前释放的下一步核验契约

当前继续按整单闭环保守持有，未开启提前释放。要放宽需逐项满足并持久化：

- 原任务/车辆/步骤/地图版本/资源身份与原命令匹配；原入站命令被接受不等于已离开候车位。
- 当前坐标属于已核定车端地图及坐标系，定位质量有效、时间连续且未断连；需车体轮廓、定位误差和安全余量，而非仅判断车中心越线。
- 车体完全离开候车区域，且已原子取得后续倒料/通道路权，后车不与前车入站路径发生未配置冲突。
- 若同一任务多个步骤保留候车位，必须明确哪些租约可转交；不能只删其中一行就当作完成释放。
- 证据、租约版本核对、释放事务与回执必须可重启复核；回执丢失不可重复释放，取消/断连/证据过期继续保持。
- 需补正常离位、边界抖动、仅中心出区、旧坐标、地图切换、原命令失败、取消、并发申请和释放提交后崩溃的隔离测试。

真实车体尺寸、定位误差、当前地图及设备许可语义尚未核定，不能据此自动启用现场提前释放。下一批先做只读离位证据评估，再决定模拟释放事务。
