# 双车双工位竞争与交接测试

本轮新增独立的双车测试会话、Web观察面板及PLC模拟器 fleet-box-action-v1 接口。单车顺序循环保持原入口；双车测试不以车辆固定工位作为通过条件，不提供新的运动执行器。

## 启动和操作

使用发布包 `高级工具\多车联调\启动多车联调Web.cmd`，车辆范围为AGV-01、AGV-02，地址仍为 http://127.0.0.1:5199/。先停止原启动模式；启动器不接管其他进程，不在启动时发车。PLC人工联调台需1.6.0或以上，使用原本机S7端口10200和控制端口10201。

业务任务页展开“双车双工位 · 竞争与交接测试”。每次仅选择一组，每工位一次任务，核对现场后启动：

| 用例 | 呼叫触发 |
| --- | --- |
| 错峰 | 工位一先呼叫；原任务取箱确认步骤完成后触发工位二 |
| 同时 | 模拟PLC在同一内存锁内置两工位P呼叫；调度按可用车辆与路线分配 |
| 交接 | 第一笔任务进入倒料执行步骤后触发工位二；若轮询时已完成倒料，仍释放第二呼叫，但是否覆盖了重叠场景需查原时间线 |

调度按当前任务、车辆状态、地图和路线规则选车，两任务并发上限为2，参与车范围限制为启动时明确的两台；不会为测试强制固定车站关系。候车位和道路资源可能使第二车留在原工位等待；不能因其未立即进入LM5就判失败。

## 启动条件与边界

- 两车在线、定位有效且停稳，无未完成车端任务。现场确认无载初态、箱体和通行区域；本入口不发独立顶升动作。
- 两车初始停车站点不同。地图、车端坐标绑定及两车最大载箱包络必须分别核定，不能复制AGV-01的确认标记给AGV-02。
- 两工位旧呼叫、返箱责任及共享倒料握手均闭合，无原业务任务和交通占用；单车运行记录已结束。
- 当前28阶段契约开启；候车位需有独立容量1资源，且不与倒料节点共用。容量检查不证明候车位几何位置不挡出口，必须现场核对。
- 仅允许所有PLC连接为本机模拟器。关闭独立自动建单器，由本会话接受呼叫后创建不指定车辆的原业务任务。现有建单去重、调度、PLC握手、路权及出区执行器继续负责执行。
- 三组用例不自动注入实车断网、定位失效或急停。此类异常应按现场可控条件单独测试，不能由模拟通过推断实车通过。

## 信号及责任

模拟器只产生P呼叫和P箱体反馈。H信号由调度写入；共享Ready和Done沿用原模拟PLC握手。箱体变化需要本任务原运输步骤完成、原车端动作成功、车辆身份及当前停靠状态核对，不使用H通知倒推取放箱。两工位分别绑定原任务及车辆，反馈重试不得改身份。

前车实际出区并满足PLC闭合、原设备交接记录完成后，后车才可取得倒料许可。前车返箱收尾继续按其原工位和交接记录执行，不清后车共享位。相关执行规则复用当前28阶段执行器；本次增加测试与观察入口，不声称已取得双车实测结论。

## 异常及收尾

停止按钮仅停止新增呼叫，原任务和已释放呼叫仍需收尾。任一车数据失效、PLC失效或地图参数变化时会话转Hold，停止新呼叫和新派车；已有运动由原任务安全机制处理，不视为物理急停。重启加载未闭合记录必须Hold；切普通启动模式也不能绕过原会话保护。

核对后续接沿用原运行和原任务。模拟器若重启丢失会话，不自动重建活动点位；须按原任务恢复界面和现场事实处理。核对结束需要原任务终结、握手基线及交通资源闭合，不能清数据库代替。

本组结束不会给两车同时发送LM7导航。返待机需先配置独立停车位及路线，再按现场指令处理。

## 结果记录

Web集中展示两站任务、实际分配车辆、等待原因、持有资源及出区交接，详情链接可查看原任务PLC条件与时间线。人工验收项目默认“待核验”，保存在本机浏览器、按运行编号隔离。导出JSON包含当前观察、观察新鲜度和人工记录；任务诊断包仍由原任务详情导出。人工记录不是后台审计签名，模拟P值不证明真实传感器或机械动作完成。

用例仅在两车实际参与、无重复领取或冲突派车、正确任务取得许可、前车出区闭合后交接、无堵出口、无跨车借用状态等事实核对后判通过。任务完成不等于这些验收项目自动通过。

## 隔离验证

`tools/FleetTestSmokeTest` 验证三组触发、同申请幂等、任务/车辆范围、停止新增、数据失效、重启保护及模式互斥。

`tools/PlcHandshakeLabSmokeTest` 的FleetTests验证同批呼叫、工位/任务/车辆绑定、原动作反馈、过期/断连拒绝及停止后原返箱收尾；原单车和S7回归保留。

软件隔离验证不代表已完成双车现场验收。

2026-10-27本轮已通过：双车会话45项、原单车会话87项（含22项动作反馈选择）、28阶段集成98项、候车位/路权20项、模拟PLC新增双车12项及其原有S7/恢复/证据回归；Web类型检查和构建通过。当前现场仅AGV-01已有核定包络，AGV-02仍须独立核定；两车离线时不会放行测试启动。
