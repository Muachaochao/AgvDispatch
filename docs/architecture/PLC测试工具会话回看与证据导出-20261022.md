# PLC测试工具1.3.0：会话回看与证据导出

用户要求先修复导出阻塞、增加历史回看和一键证据包，再开展厂家现场测试。本次仅修改独立PLC工具及其回归、发布脚本，不修改调度执行器、PLC协议或现有实例状态。

## 实现

- `NetworkLab.CaptureSession` 在通信锁内仅刷新日志、取得独立读取句柄/字节上限和本会话配置。流式CSV、报告和ZIP处理移到锁外，WPF后台执行。日志继续增长时，导出只读取已捕获前缀。已捕获会话即使原Lab随后关闭仍可读取。
- 导出使用同目录临时文件，完成并刷新后再替换目标；正常取消和失败清理临时文件，保留原目标。禁止覆盖源日志和同名配置。导出写盘故障不标记原PLC日志故障，不停止S7；原日志自身写入失败的停服机制保持。
- 独立历史窗口不持有NetworkLab或S7服务，按工位/轮次重建28阶段结果、车辆/任务和复测记录。只保存最近500条事件预览，完整日志仍可导出。原日志和点位不改写，不用历史记录恢复PLC。原会话损坏尾部或阶段结构异常会计数提示；缺少有效相邻配置时不生成点表。
- ZIP包含原始日志、配置（存在时）、点表（有效时）、CSV、阶段报告、摘要及逐文件SHA256清单。区分源工具版本和导出工具版本。只包含本工具记录，不采集调度数据库/实车日志/授权；包内哈希不替代源记录真实性或厂家现场验收。
- 版本升为1.3.0；发布脚本从csproj读取版本，不再多处硬编码。实际发布EXE的UI自检通过后才切换当前指针。

## 验证

原137项离线/文件桥接、45项S7/HSL、39项恢复与阶段检查保持通过。新增26项会话证据检查，合计247项：

- 故意阻塞CSV输出，在其尚未结束时完成真实TCP S7读取和P点输入，验证没有占用通信锁。
- 超过500条日志全量导出、固定前缀不含后来追加事件、CSV转义。
- 两轮、失败及复测重建、未测保留、原版本保留、历史回看不改原日志。
- ZIP逐条数据长度与SHA256复算、配置/点表/报告齐全。
- 取消、模拟导出写盘失败、目标文件保护和临时文件清理。
- 原Lab关闭后已捕获快照仍可导出；损坏尾部、缺配置的提示及原文留存。

WPF自检保留原P/H隔离、真实TCP写入、启停和断连旧值检查，并新增后台证据ZIP生成、只读历史28阶段以及历史窗口关闭/渲染。源码与实际发布EXE分别运行。

本轮是工具回归，不重跑或冒称厂家车辆的多车、机械联锁和现场断网验收。下一步使用厂家核定点表在独立S7人工模式逐阶段记录两轮、多车交接与断网恢复，导出对应证据包。
