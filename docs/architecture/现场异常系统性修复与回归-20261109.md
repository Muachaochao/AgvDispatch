## 时间策略

默认阈值：`10 / 30 / 60 / 120` 秒。

- 0～10 秒：等待车端短时避障自动恢复，不取消、不重发。
- 10 秒：开始核验车端原任务状态、停稳、定位、载荷、PLC、路权和替代路线；可发送取消原导航请求，但不发送第二条导航。
- 30 秒：持续受阻预警。
- 60 秒：持续受阻报警，保留任务、载荷、PLC 责任和路权。
- 120 秒：建议封锁实际受阻方向及必要上游汇入；无安全路线时冻结任务并进入安全点或人工处置。

自动发送的核心门槛不是秒数，而是以下条件全部成立：

1. 原导航链及原车相关分段任务具有明确终态；原业务任务继续保留，不要求也不得把业务任务提前完成。
2. 车辆在线、定位可信并连续停稳。
3. 载荷和箱体归属未改变。
4. 起终点是地图中的可信站点或有明确直线后退证据。
5. PLC 信号新鲜、无故障且原握手责任可闭合。
6. 替代路线已经取得路权，旧路权交接和共享设备归属一致。

| 3055 结果未知 | 禁止重复发送，只核对实时位置和停稳 |
| 人工把车移到错误站点 | 起点不一致时拒绝发送 |

| 当前 W 窗口完成但业务未到目的站 | 不结束业务任务；查询使用当前窗口编号，规划使用完整路线快照 |
| 障碍持续且当前窗口停在中间可信站 | 原任务终态后只发一条剩余路线；停稳样本持久化并真正达到门槛 |
| 另一车辆占用候选路线站点 | 规划阶段排除该站点；无安全路线时 `NoRoute`，不得发送后靠车体阻塞 |
