# 创建任务：按需运行与交替循环

2026-10-25。新增统一入口，保留手动创建单次九步任务。

## 配置与入口

- CNC-001 取放箱点 LM2，CNC-002 为 LM4；倒料等待 LM5、倒料 LM6；待机 LM7。倒料等待点不作为空闲待机点。
- 工程设置保存工位和动作参数，地图发布激活并核对厂家编号、坐标和实际路线。交通资源、等待湾及实测车体配置仍由已有业务校验检查，不自动填造。
- 业务启动须显式执行根目录 `启动最新版Web.cmd --business-run-vehicle AGV-01`；切换启动模式先使用原停止入口。该参数启用业务服务及全局发送许可，保留已保存的设备连接，**不解除启动恢复屏障，也不发送任务**。默认启动仍为监视模式，升级不会恢复测试发送许可。
- 在“创建任务”切换到“正常按需运行”或“自动循环测试”，选择车辆、工位顺序和待机点；循环模式另选轮数。先查询并核对原运行，再勾选现场确认并启动。
- 循环模式须用 1.5.0 版 PLC 人工联调台，启动 S7 服务 127.0.0.1:10200，且后台点表与它匹配。工具只在该本机地址配置下开放 10201 控制端口；调度经此端口请求产生模拟 P 呼叫。不能连接正式 PLC 自动制造呼叫。

## 分工与收尾

按需运行读取真实 PLC 呼叫，不制造下一呼叫。循环测试由模拟 PLC 按所选顺序一次产生一个呼叫；一轮为所有参与工位各一次。模拟箱体与倒料反馈不代表实物动作验收。

持续运行器复用正式手动创建、九步执行、Outbox、28阶段握手及原任务查询，不另造简化业务执行器。任务 Completed、PLC责任闭合、资源释放后才计一次完成。下一工位已有呼叫就直接接续；无任何待处理呼叫且全部闭合才用独立持久化导航返回待机。返回也核验空载、顶升下降、原车端任务链、地图及路线，取得交通资源后发送。

“停止新增呼叫并收尾”通知模拟器停止新呼叫，保留已经产生的 P 和所有 H。调度完成剩余任务后回待机；该按钮不取消车辆动作。真实 PLC 若继续产生呼叫，需要由现场停止呼叫来源。未参与工位的呼叫仍保留，不会当作全局空闲。返途中新增呼叫在待机停稳后接续，不中途改派。

## 中断与限制

发送意图、参数版本、当前任务及待机链均持久化。超时、断连、故障、地图/参数版本变化、后台重启会暂停待核对，禁止自动重发。运行未结束时阻止新地图激活及额外手动导航、顶升、业务任务插入。

“核对原运行并结束记录”只结束已核验闭合且停在待机点的暂停记录，不自动续跑。未取得确定回执的发送意图不能靠此按钮释放；原请求仍须进一步核对。原业务任务异常时沿既有任务恢复流程处理，不能通过删除 JSON 清除占用。

本次隔离测试覆盖协调器与本机模拟 PLC；实车九步业务、PLC物理反馈和现场交通条件仍需现场验收。
