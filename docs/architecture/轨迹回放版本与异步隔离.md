# 历史轨迹版本与异步隔离

2026-10-14：原轨迹查询只按VehicleId/MapId/时间过滤，同一地图不同版本可能混在一条回放线中；加载期间换车/换图可能被迟到结果覆盖。

AgvTrackQueryRequest尾部新增可选MapVersionId，旧调用保持兼容；AgvTrackStore在SQLite筛选指定版本。编辑器只在工作区Published.VersionId与Project.ActiveVersionId一致时请求该运行版本，旧后台即使忽略新字段，客户端验证器也拒绝混版本数据，不补造未知历史版本。

AgvTrackReplayValidator核对车辆/地图/版本/时间范围、坐标、角度、Normal或OffRoute状态及点数/ID，排序按时间再ID。错误结果整批拒绝，避免删掉中间坏点后把两端伪连成连续路径。超过30秒采样间隔不连线，这只是展示断档阈值，不是厂家通信保证。OffRoute仍作为异常轨迹显示，不删库。

加载请求捕获车号、地图/版本和generation，换车/工作区运行版本变化/清除/离开编辑器使generation失效，读取最长15秒；迟到结果和失败不覆盖新选择。新加载先清旧轨迹，显式标注版本及10000点可能截断。此批未改变逐点定时播放模式，未做真实时间轴、倍速、拖动定位或多车同步。

23项新增验证及地图编辑器回归证据位于../commissioning/evidence/20261014-geometry-context。未连接实车，未采集现场历史数据，不代表完整ProfControl对标。
