# 地图离线编辑与在线发布

## 离线模式（打开编辑器后的默认模式）

不调用调度服务，也不连接PLC/AGV。新建、编辑点线/资源/图层、撤销重做、拓扑JSON或CSV目录导入、CAD全图与局部高清、坐标标定、结构校验、路径仿真和发布前路径矩阵均在本地执行。

点击“保存本地”保存到 `%LOCALAPPDATA%/AgvDispatch/OfflineMaps`，可用地图列表重新打开。右侧配置中的草稿备份可另存为 `.agvmap.json`；顶部“打开本地”读取此格式，并复制为一个新的独立本地项目，不继承后台运行/发布身份。保存采用临时文件提交并保留上一版 `.bak`。未完成、有结构错误的离线草稿也允许保存，但不能上传。

离线地图文件包含拓扑、图层、画布设置、CAD路径、底图路径及标定。当前不是打包格式：跨电脑使用时需另行复制CAD/底图资产，或重新选择CAD并生成底图。

“刷新”在离线时只读取本地项目。审计、后台版本历史、实时车辆与运行地图切换在离线模式不可用。关闭前请保存；新建、换地图、刷新、切模式会先保存当前本地编辑区。不会删除已有本地项目。

## 在线模式

“在线发布”仅连接服务、读取后台地图列表和工作区。原离线草稿先保存，连接失败继续保留离线模式，不自动上传、不改后台地图。

要上传当前离线地图，直接点击离线模式下的“上传草稿”。后台权限和本地结构校验通过后，创建名为“原名（离线上传）”的新后台项目并保存草稿。不会覆盖已有地图，不自动发布、不自动激活。上传后进入在线模式，用户另行校验发布与安全切换。

CAD缓存与本地标定不直接充当生产资产：上传后需确认服务能读取CAD源路径，在后台生成底图并核对/保存标定。创建与保存是两次后台操作；保存失败时可能留下新建的空草稿，界面会显示其编号，本地文件继续保留。再次上传会创建新的项目，不承诺上传操作的跨进程幂等性。

在线模式继续使用原后台草稿版本、编辑令牌、权限、审计、发布及安全切换流程。切回离线前，将当前在线编辑区保存为独立本地副本（新编号），不是修改后台运行版本。

## 分层

- Application：`ILocalMapEditorStore` 定义本地存储、导入、校验、CAD、标定契约，不含发布和激活API。
- Infrastructure/Maps/Offline：`LocalMapEditorStore` 管理独立文件与本地渲染，复用CAD、导入、校验和标定实现；不使用数据库或设备连接。
- WPF：模式协调、命令开关及本地/远端请求路由。离线禁止后台轮询；模式版本号和地图编号阻止迟到的在线响应进入新编辑区。
- Service：保留原在线生产数据与发布/激活边界，不启动服务即可编辑本地文件。

可使用 `AgvDispatch.Wpf.exe --map-editor` 直接打开独立离线编辑器，不创建主调度窗口。正常启动仍可从地图模块进入。

## 验证与限制

地图编辑烟测包含“所有后台调用立即抛异常”的客户端，验证离线启动、新建、保存、重开、导入、CAD/局部高清、标定、校验、撤销等不访问后台；另验证连接只读、显式上传不发布/激活，以及原在线编辑回归与界面渲染。
