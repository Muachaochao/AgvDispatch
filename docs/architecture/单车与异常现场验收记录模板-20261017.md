本文件是待执行模板，不是验收通过报告。所有用例初始状态为“未执行”。不得用隔离夹具、合成地图、界面动画或写入回读替代现场证据。

## 正常整趟

| 步骤 | 必须记录的原始依据 | 结果 |
|---|---|---|
| 1 前往取货 | 原车原运输接受/运行/完成；实际取箱动作；实际箱体离开观察 | 未执行 |
| 2 确认取走 | P2=0的有效采样；P6/P7通知；P5/P6复位；本轮检查点 | 未执行 |
| 3 前往等待位 | 同车原运输身份、实际到等待站、对应路权 | 未执行 |
| 4 消费Ready | D1置1、Ready有效、D1撤销及PLC消费Ready=0；PLC内部保留预约 | 未执行 |
| 5 进入倒料位 | 原运输及实际到位；不能以准备命令替代到位 | 未执行 |
| 6 本轮倒料 | 原Done低基线、本轮D2通知、实际倒料动作、Done高反馈及时间 | 未执行 |
| 7 返回空箱 | 离开许可、原返程任务、实际带空箱返回；D2保持符合PLC程序 | 未执行 |
| 8 放空箱 | 原放箱动作、P8通知、实际空箱在位及P2=1 | 未执行 |
| 9 收尾 | 原站新鲜定位、结构化返程证据、D2撤销/Done复位、P7/P8等收尾及归属释放依据 | 未执行 |

每个步骤填写实际采集时间和记录时间；13位信号不具备原生业务周期号时，还需保存现有身份/恢复核对依据。不能仅用BOOL高低判断是同一轮。

## 异常用例

| 编号 | 条件 | 期望行为 | 状态 |
|---|---|---|---|
| E01 | Ready在到等待位之前已为1 | 按明确消费握手推进，不要求必须新出现上升沿；PLC保留本轮预约 | 未执行 |
| E02 | 上轮Done残留1 | 不直接认定本轮倒料完成，不擅自清PLC输入位 | 未执行 |
| E03 | PLC通知写入结果不明 | 保留原意图/阶段；不自动重发，现场核对后续接 | 未执行 |
| E04 | 调度在本轮中断后重启 | 原Task/Step/厂家任务身份保留，恢复核对前不推进 | 未执行 |
| E05 | PLC重启/身份或周期变化 | 旧高电平不作为本轮业务证据；按身份和恢复机制处置 | 未执行 |
| E06 | 箱体检测卡住、抖动或质量失效 | 不按未知=0、不重复取放，不错误完成收尾 | 未执行 |
| E07 | 车辆任务完成但原站定位不符 | 不能将数据库终态当作实际返程到位并释放设备归属 | 未执行 |
| E08 | 工位或倒料机故障 | 保留原状态及归属；故障恢复不等于跳过原握手 | 未执行 |
| E09 | 倒料完成后返程未闭合 | D2保持及资源保留符合约定；PLC不会因延后复位造成流程自锁 | 未执行 |
| E10 | 取消时仍有箱体/载荷或未知运输结果 | 保留原身份和物料核对，不把取消受理当作现场已停止 | 未执行 |
| E11 | 网络断连后旧值仍在缓存 | 页面标记失效，后台不以旧值自动推进 | 未执行 |
| E12 | 混用旧Web/接入层/主服务 | 批次差异明确可见；检查不当作提交授权 | 未执行 |

所有异常用例应在现场确定的受控联调条件下安排；本模板不要求在线生产时直接拔电、改传感器或干扰运动车辆。
