# Web工程配置、方案库与任务路线联动

更新：2026-10-18。Web是当前主要操作界面，后台继续使用原C# Service和Robokit TCP。

## 操作顺序

1. 从项目根目录“发布包/启动最新版Web.cmd”打开软件；启动器等待本版后台就绪，默认设备通信及执行关闭。退出演示后操作真实后台配置。
2. 工程编辑中准备导航节点、厂家站点编号、道路及交通资源；保存后台草稿、校验发布，再到地图查看按原安全切换流程激活。业务编号与厂家编号分列，不能互相替代。
3. 顶部“工程配置”→“读取后台配置”。填写倒料PLC工位、等待点、倒料点、取货映射、四段末站动作及步骤超时；“逐步校验”定位缺项，“校验并保存任务参数”复用原Service校验与revision保护。保存不是启动任务。
4. 同页维护厂家地图绑定：车辆、本地地图/版本、厂家地图名、已确认MD5及核对依据。新增绑定默认不勾坐标确认；人工声明必须有真实资料。“只读查询车端版本／站点”复用原只读核验。无现场资料时保留未核定，不填写猜测值。保存只更新绑定，保留PLC、车辆和全局开关，后台要求时受控重启生效。
5. “工程编辑”→“方案管理”→“保存当前稿到服务端”。可读取方案、查看历史、预览当前或历史版本、下载备份。加载先进入核对预览，确认后才替换编辑稿，不会激活运行地图。恢复旧内容再次保存会形成新版本，原历史保留；未改变内容重复保存不增加历史。
6. “任务列表”或大屏任务详情→选择步骤。内嵌只读图显示该任务持久化的原命令路线、业务/厂家站点及动作，关联现有PLC条件和持有资源。PLC步骤关联前一运输段。缺原快照、观察过期、归属或地图ID/版本/摘要不一致会拒绝关联。图上端点不是车辆实时位置，也不代表可以通行。

## 保存范围和限制

- 服务端方案保存导航编辑稿、场景、车辆配置稿和顺序航点；不包含PLC现场点表、任务数据库、运行开关或全部部署配置。任务参数和地图绑定另由原Service保存。
- 根固定入口将方案库放在“发布包/运行数据/Web工程方案”，与版本目录分离，换发布版本仍可读取。直接运行单个完整包的入口默认使用该版本Web/data/projects；可传入`--project-store-path`选择独立目录。HTTP不接受客户端指定本机文件路径。
- 单方案JSON最多4MiB、最多100方案/每方案32历史版本；超限明确拒绝，不自动清理。导出后可另存新方案。下载的JSON可经原文件加载入口预览恢复。
- 多页面保存使用revision比较；过期编辑拒绝覆盖。方案写入有进程内及文件锁、原子替换和摘要检查。文件级库不是数据库事务或全场灾备工具。
- 断连、演示切换或后台/地图上下文变化后，配置稿保留但锁定，重新读取再校验，避免旧响应覆盖新页面。
- 任务路线联动位于任务详情的二维只读图；中央Three.js大屏尚未自动对当前任务全图着色。不能称为厂家激光底图、三维点云或轨迹回放。
- 本机127.0.0.1访问，未增加局域网多人认证。配置保存不会自动打开现场通信、控制或上传。
