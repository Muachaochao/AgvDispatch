# 联调检查页、运行身份和创建提交回归

日期：2026-10-17；依据当前主工程和有效13位PLC握手契约。没有读取失效归档，没有开启现场通信或执行。

## 本批交付

Web顶部新增“联调检查”。主服务提供统一只读检查接口，浏览器不自行拼造通过结果。它不创建任务、不操作PLC、不申请/释放路权、不放行恢复，也不自动访问车端核验接口。

顶栏及检查页显示：主Service版本、Service程序集SHA256构建身份、服务进程启动时间、原执行器/持久化新握手模式、当前配置契约与软件支持版本。不能仅用恒定的1.0.0.0判断是不是新程序；同版本号后台重启也会使旧检查失效。构建指纹是Service程序集的身份，不是所有部署文件、配置或PLC固件的整体校验。

## 第一次使用的顺序

1. 部署相匹配的主Service及Web接入层，先以原有受控配置启动后台，再启动Web。Web启动脚本不会启动主Service。
2. 点击“联调检查”，先核对后台构建、启动时间、模式、运行地图和参数修订。
3. 选择后台配置的工位和已观察到的车辆，点击“重新检查”。没有车辆观察时可先跳到车辆配置；不会将保存的车辆配置冒充在线车辆。
4. 按阻塞和待核对项处理。保存配置不等于活动配置已经改变；重启待生效会单独显示。检查页不自动重启或开启开关。
5. 读取13位信号，区分“点位/访问配置”和“采样质量/新鲜度”。数据有效性通过不等于电平满足本步骤，业务期望看原任务详情。
6. 条件允许时显式点击“只读核对四段路线”，复用原地图/厂家站点/路线预检。此操作可能进行车端只读查询，不发送导航。没有车辆、观察过期或后台不支持时不能凭本地路线当作核验成功。
7. 到任务列表或原创建入口提交单车任务。正式提交和执行仍重新检查地图、参数、车辆、工位、协议和路权，不消费此检查页的“通过”作为授权凭证。
8. 运行中看九步、握手阶段和等待原因；异常按原恢复流程核对，完成后导出联调包。

## 检查内容及缺项导航

| 分类 | 当前检查 | 处理入口 |
|---|---|---|
| 后台 | SQLite连接、保存配置待重启、主服务身份 | 页内后台部署/重启说明；离线或旧服务也能打开说明 |
| 地图 | 活动地图/版本、采集窗口一致性 | Web工程编辑→地图；正式运行切换仍在WPF |
| 执行门禁 | 地图/恢复门禁、启动恢复批次 | 页内WPF/Web任务详情恢复路径说明 |
| 开关 | 创建、调度、步骤、Outbox、PLC通信/写入、AGV通信/指令 | 活动配置说明，不自动打开开关 |
| 握手 | 当前模式、配置版本、软件支持版本 | 页内时序及新契约启用边界说明 |
| 工位 | 工位映射、九步静态配置、当前工位业务条件 | WPF任务中心“任务参数·动作/站点/步骤超时”；逐步缺项原文可展开 |
| 车辆 | 观察列表、接单条件、当前地图唯一绑定、坐标核定记录 | Web车辆配置/实时车辆列表；绑定在WPF系统设置→Robokit地图绑定 |
| 路线 | 当前站点到取货点本地可达；显式车端四段核验 | 地图道路方向及原路线预检接口 |
| 信号 | 13位地址/方向/可写性、值、质量、采集时间 | 页内13位信号表 |
| 业务前提 | 工位通讯正常、工位无故障、箱体在位、倒料机无故障 | 读取同一原始缓存按新鲜度核验；未知不当作无故障 |

结果分为“观察通过、阻塞、待核对、说明”。缺失/禁用/坏质量/过期信号不能显示为当前有效通过，未知值不填0。输出回读不是PLC业务ACK；Ready/Done等电平不能脱离业务阶段单独判定合格。

“观察通过”也不是放行许可。页面只保留15秒观察窗口，并要求推送连接新鲜、主服务构建/启动时间和运行地图一致；失效后显示历史观察。后台参数或现场状态可能在窗口内改变，路线和提交会重新核验。页面不承诺跨接口原子快照，也不自动续期历史检查。

工位/车辆选择改变会重新读取，旧请求响应不能覆盖新选择。切换地图、后台重启、断连和页面卸载会取消原请求并清除路线核验。普通的同身份2秒推送不会清除核验结果。缺项导航不保存、不覆盖已有工程编辑稿。

当前检查页没有新增PLC内部状态、实车身份协议或自动PLC固件版本发现；配置声明匹配仍需现场核定。地图绑定通过仅是保存配置检查，车端实际一致性需原只读核验。交通容量/物理区域释放仍以既有后台逻辑为准。

- 前端17项测试及类型检查/生产构建通过，覆盖断连、过期、未来时间、同版本号重启、构建或地图变化后撤销检查。

PLC与物理反馈仍在模拟边界；上述通过不替代S7/HSL网络、现场PLC程序或机械动作验收。依赖ImageSharp既有安全告警、Three构建体积提示仍存在。本批不是全解决方案所有工具都已重跑。

## 部署边界

Web试用包更新不会自动替换主服务。新检查接口、身份和模式字段需要本次主Service代码；旧服务不支持时明确报错和提供部署说明，不回退合成数据。现场主服务未被自动替换、重启或启用任何设备执行开关。
