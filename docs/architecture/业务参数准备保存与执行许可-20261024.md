# 业务参数准备保存与执行许可

任务参数属于运行地图上的配置准备。此前保存入口同时依赖新增任务门禁和 PLC 写入许可：启动恢复未放行或 PLC 写入关闭时，工程人员无法先保存工位、业务站点及动作参数，形成准备配置必须先允许执行的循环依赖。

现在配置准备与执行许可分开：

- 当前地图处于 `Running`、已加载运行图且没有未结束业务任务时，可以校验并保存任务参数；真实切图收尾、保持暂停或地图未初始化时仍拒绝保存。
- 参数准备校验保留点位归属、启用状态、地址、Bool 类型、读写方向、站点唯一映射、路线连通和末站动作检查。PLC 写入开关关闭不阻止准备配置；这不改变写入开关，也不发送信号。
- 实际建单和执行继续使用严格的执行许可检查。保存成功不等于允许派车、不解除启动恢复屏障，也不启用握手、出站命令或调度。
- 保存仍持有地图控制锁，核对参数修订和运行地图版本，先验证再原子持久化。重启后读取同一参数文件。

模拟 PLC 的 `CNC-001`、`CNC-002`、`DUMPER-001` 信号归属来自后台加载的点表，连接正常只证明通信采集。取货点、等待点、倒料点及四段车辆动作在 Web「工程工具 → 任务参数与厂家地图绑定」中读取、编辑和保存。

配置检查通过只证明当前启用模式要求的配置可解析。首段车辆路线、厂家地图身份、动态路权及车辆状态仍在建单或执行时检查；启用完整 28 阶段业务前，还须核对该模式要求的倒料资源边界、整车和载箱包络等现场配置。不得用模拟点表或显示区域替代实际核定。
