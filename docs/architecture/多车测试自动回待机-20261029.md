# 多车测试自动回待机

## 行为

多车测试原先在业务任务和 28 阶段 PLC 握手闭合后直接标记完成，车辆停留在各自
取货点。当前实现增加独立的 `ReturningStandby` 收尾阶段：

1. 只有全部业务任务、PLC 握手、返箱责任和交通资源闭合后才开始。
2. 按 `TaskParameterRuntime.Standbys` 的车辆池授权、优先级和唯一站点为每辆车分配
   待机位。当前现场配置为 `LM29`、`LM30`、`LM31`。
3. 发送前重新核对车辆健康、停车状态、当前站点、运行地图、可达路线、车端路线和
   交通资源。路线暂时被占用时保持原位等待。
4. 每辆车仅发送一次待机导航。发送结果不确定时进入 Hold，禁止自动重发。
5. 厂家导航完成、车辆停稳、实际站点和坐标均与待机点一致后，才释放该车路权。
6. 所有车辆都完成停靠后，本组才从 `ReturningStandby` 变为 `Completed`。

## 安全边界

- 自动回待机不会替代原返箱流程，不会在 PLC 握手闭合前移动车辆。
- 同一待机节点只分配给一辆车；非本轮车辆已经占用的待机点不会被复用。
- Web 多车测试页显示每辆车分配的待机点、状态、路线和厂家任务身份。
- 可通过 `FleetTest:ReturnToStandby=false` 显式关闭，默认开启。
