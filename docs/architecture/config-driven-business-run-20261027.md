# 工位、车辆池与运行页面配置化（2026-10-27）

## 已交付

- 业务按需／循环入口读取后台工位配置，不再限定 CNC-001、CNC-002 或 A→B 四个选项。支持搜索、加入、移除及上下调整执行顺序；后台允许 1–1000 个配置工位，拒绝未知工位、空编号及重复编号。
- 车辆列表按所选工位车辆池的交集生成，显示适用车辆数量。后台仍独立验证池内授权，不能绕过页面跨池派车。连续业务运行记录仍绑定本次选定的一台车。
- 待机位随工程版本保存，包含业务站点、车辆池、明确适用车辆及优先级；页面随车辆显示对应待机位。保存检查停靠用途、站点唯一性和与取放／倒料站点重叠；同一冻结工程版本不得改写待机绑定。
- 工程模拟页读取所选冻结版本的工位、车辆、车辆池、倒料设备、待机位和交通资源。可选择参与工位、离线车辆、封锁资源、呼叫轮数及间隔，无需填写示例编号。切换版本清除旧选项和旧报告。
- 模拟同轮呼叫同时进入调度队列，根据优先级、车辆池和资源安排；页面明确区分其与单车循环的接续顺序。
- PLC 测试器呼叫计划从实际点表发现工位；呼叫计划和竞争测试不再只接受两个人工编号。点表容量支持 1000 个工位的 8005 项定义。
- 空载 PLC 联调页显示后台真实车辆、工位及路线；移除虚构默认 LM 站点和固定 DB 地址操作提示。信号地址应查询当前绑定点表。

## 使用入口

隔离预览：`http://127.0.0.1:5297/#/engineering`。

工程配置中心维护工位、车辆、车辆池、倒料设备、待机位 → 保存 → 校验 → 发布工程版本 → 模拟测试选择版本。工程示例中的 300／5 仅为可修改的示例数量，不是固定厂区配置。更新现场版本需使用原 5199 受控升级流程。

## 执行能力边界

- 真实九步执行器当前共用一组倒料设备和四段动作。多个倒料设备或不同动作模板不会静默合并应用，而是明确拒绝；多设备并行真实执行仍需继续开发。
- 业务连续运行记录一次绑定一台车；车辆池授权与多车预约模拟已经配置化，但不代表已完成真实多车连续业务编排和实车验收。
- 配置化不取消原任务归属、未知发送结果、PLC握手、出区包络、地图切换及启动恢复核对。
