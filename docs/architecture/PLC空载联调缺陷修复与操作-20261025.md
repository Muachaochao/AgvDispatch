# PLC空载联调缺陷修复与操作（2026-10-25）

本轮针对 CNC-001 / AGV-01 的独立模拟 PLC 空载测试。正式28阶段生产流程、倒料区退出核验及PLC物料闭环仍保持原有门禁，不能用本轮结果替代验收。

## 核对依据

- 现场持久化记录 c29435c47b8f494eb6896a176ab8e068：2026-10-24 23:58:43（北京时间）进入 Completed；记录含三段导航和两次顶升动作，末次下降动作已完成。
- 同轮多次出现行驶中“当前真实站点未知”，导致原导航查询被跳过。
- Service日志反复出现 Named Pipe CreateServerPipe 的 Access denied。
- 启动脚本、最新版Web.json 指向不同批次；专用联调入口未沿用固定 Web 工程方案路径。

## 修复清单

| 问题 | 修复 |
| --- | --- |
| 重启后等待阶段能自动继续发后续指令 | 所有未结束阶段均转 Hold，保留原动作及输出，不自动续跑 |
| 行驶中站点为空遮住原导航查询 | 仅到站操作要求站点；行驶阶段持续查询原任务 |
| 只比较目标站可能冒认其他导航 | 校验原任务编号、厂家编号、车辆、车端地图和目标 |
| 顶升结果不确定但遥测到位会被算完成 | 必须匹配原请求、动作、车辆、明确应答及新鲜完成反馈 |
| 父流程未先保存动作意图 | 导航和顶升调用前写入 Sending 子记录；重启冻结避免重复发送 |
| 旧Ready/Done高电平被当新许可 | 发对应H申请前要求相应P为0，再等待新许可 |
| 复位覆盖未决写入、未撤输入和未结束动作 | 拦截未决写入、检查原动作结束及三个P为0；每笔复位持久化意图并回读 |
| 新一轮覆盖上一轮证据 | 重新武装前归档至 plc-cycle-test.json.history/周期编号.json；历史请求编号不得重放成新一轮 |
| 联调打开全局PLC写权限 | 正式PLC写保持关闭；独立连接只开放127.0.0.1:10200的六个固定H点 |
| 人工导航/顶升可与自动流程交叉下发 | 联调启动模式独占命令入口，切换模式后才能手动测试 |
| 连接恢复后自动继续本轮 | 状态失效转Hold，不自动恢复发送许可 |
| 管道实例创建拒绝访问/无界并发 | 服务所有者增加创建实例权限；固定8个连接工作者；读取超时取消实际读取 |
| 页面轮询重叠、旧状态放行、超时后新编号重试 | 单个在途轮询；断连禁武装；会话保留原请求编号并查询原记录 |
| 页面缺少复位及当前PLC操作提示 | 增加核对后复位按钮与逐阶段点位提示 |
| 日常启动数据路径不一致 | 日常入口显式使用 --daily-data，固定后台5199及Web工程方案路径 |

## PLC人工操作

每轮只针对 CNC-001；车辆无箱空载、机构下降、路线清空、厂家低速，确认后手工武装。下表依实际阶段和反馈操作，不能提前连按。

| 等待状态/位置 | PLC人工操作 |
| --- | --- |
| 已武装，箱体检测DB1.DBX0.1=1，Ready/Done/H均为0 | 满箱呼叫DB1.DBX0.0置1 |
| 呼叫响应DB1.DBX0.4=1 | 满箱呼叫DB1.DBX0.0清0；随后取料站顶升 |
| 到等待站LM5，等待位申请DB1.DBX610.0=1 | Ready DB1.DBX610.2置1 |
| 等待位申请DB1.DBX610.0=0 | Ready DB1.DBX610.2清0；随后车辆前往LM6 |
| 到LM6，倒料周期DB1.DBX610.1=1 | 确认本次模拟完成后，Done DB1.DBX610.3置1 |
| 返回LM2，倒料周期DB1.DBX610.1=0 | Done DB1.DBX610.3清0；随后自动下降并清H |
| 页面Completed，H全部归0 | 本轮结束；新一轮必须重新确认并武装 |

当前默认每阶段超时300秒。忘记给信号而超时会冻结，不会通过晚到信号自动续跑。复位不承担下降、返程或取消原动作；不满足复位条件会给出阻止原因。未决写入不能用反复点击复位消除。

## 隔离验证

- tools/PlcCycleTestSmokeTest：完整流程及重启、超时、任务替换、顶升不确定、写回包丢失、复位、模拟PLC边界。
- tools/NavigationRouteSmokeTest：3051路线、任务身份、回包丢失、实车到站反馈；仅回环协议模拟器。
- AgvDispatch.Web/scripts/plc-cycle-browser-check.mjs：浏览器请求丢失、刷新同编号、单个轮询、断连禁用、复位和PLC提示；仅本地HTTP夹具。
- tools/WebAdapterSmokeTest：隔离数据库、临时端口、后台/Web进程；新增24个并发管道只读查询。

这些验证不发送实车动作，也不证明带料生产或真实倒料区域安全条件已经满足。

本批验证结果：新联调28项断言、3051导航44项、Web后台111项、数据库及手动建单7项、前端单元测试144项、浏览器联调7项，均通过。构建仍提示既有ImageSharp依赖漏洞和Three.js分包体积警告，未将它们计入本批已修复问题。
