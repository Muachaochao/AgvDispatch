# Web等待记录联动阻塞链详情

2026-10-18。本批用于当前快捷AGV/Robokit TCP主工程的交通观察，不改变控制协议、资源归属或释放策略。

## 使用

启动最新版Web，进入调度大屏，滚动至“交通等待队列”，点击某行“阻塞链”。详情包括原任务/步骤、实际资源占用者、同任务另一等待步骤、释放核验要求和最近关联路权事件。点击“定位阻塞 资源编号”关闭详情并定位中央地图；点击“查看任务”转入原任务详情。没有有效地图边界或观察失效时不定位。

每5秒重新读取；超过7秒、后台失联或地图/数据源改变时，旧观察的联动禁用或清空。关闭后可从新队列记录重新打开。筛选、分页、地图上下文变化关闭旧详情。

## 关系与证据

后台通过同一SQLite只读事务取得请求、租约、任务、步骤、原命令状态、路权事件与人工处置审计。资源边沿用实际容量冲突观察；同一任务保留前一步占用、另一步等待时，以明确标注的“同任务等待”边连接，不能当作资源占用。已完成步骤、终态/未知任务不会借历史等待请求生成当前依赖。

最多展开32个步骤、128条边和8层；达到限制或资料不足明确提示，不能用截断结果证明无阻塞。循环只表示观察到依赖环，不自动判为死锁；汇聚到同一占用者不当作环。缺原记录、归属不一致和未知状态明确展示，不补造路线或现场状态。

释放条件是核验规则，包含：原任务/步骤/车辆归属、正常交接或收尾、逐段或空间释放所需定位证据、异常/取消保留的人工核对。状态区分已观察、未核验、未知、需要复核；已观察数据库归属不是放行许可。本查询不运行释放评估、不提供解锁/调优先级/派车操作。车辆结束或租约心跳过期不会因此自动释放。

最近事件只取本次展开任务/步骤的路权生命周期事件及人工解锁审计，合并按时间显示最多50条；超过数量明确标注。不用全场同名资源事件补历史。历史人工处置不证明当前租约已解除；空历史不代表从未发生。此处不提供全量历史检索。

## 接口与地图保护

新增只读Named Pipe GetTrafficBlocking和POST /api/traffic/blocking。Web要求原任务/步骤、预期活动图ID、版本和内容摘要，查询前后再核对地图；不同上下文返回409。沿用View权限，不开放通用IPC透传。原子数据库读不等于车辆或PLC物理现场的原子观察。

浏览器演示只提供明确标注的合成单跳关系及演示事件，不发后台控制请求，不代表真实多跳链验收。原生多跳能力使用独立Service、唯一管道、隔离SQLite的模拟夹具验证。

## 验收边界

真实本车返回、厂家取消/重复任务行为、现场PLC身份及坐标对齐仍待资料核定。现场控制、上传和自动开发任务继续关闭。下一步适合补多车连续冲突、断连和切图组合回归，核对详情过期与资源保留的联动。
