# 障碍受阻状态与原任务恢复完善

日期：2026-10-30。

## 当前实现与本次修复

当前采用 Robokit 指定路径导航。原有多车测试已将 Blocked / 非 Fatal 52200 视为该车局部等待，继续查询原任务，其他车辆和模拟 PLC 继续运行。本次核查发现单车流程仅按 52200 编号豁免报警，可能吞掉同编号 Fatal；新导航发送和任务完成推进也需要统一检查当前受阻状态。

本次统一 `AgvObstaclePolicy`：Blocked=true 或非 Fatal 52200 属于受阻；Fatal、其他 Error 及急停保留安全优先级。普通受阻不触发全组暂停，不取消、补发或自动改道。新导航命令须取得已知无阻挡状态；收到原任务 Completed 时，也须有同车新鲜 Good、安全状态明确的遥测才推进步骤，避免受阻时提前释放路权或推进握手。

采集缓存记录每车本段连续受阻起点及最后一次有效解除观察。只用递增、有效且连续的遥测累计；断连、失败、超时缺口及乱序采样中断连续计时。服务重启后重新观察，不追认停机期间的持续时长。

系统快照新增 `agvs[].obstacle`：`state` 为 Clear / Blocked / Prolonged / SafetyStop / Unknown，附 `since`、`durationSeconds`、`lastClearedAt`、`source`、处置说明、导航策略和局部轨迹证据说明。30 秒为本项目持续受阻提醒阈值，不是厂家超时、取消或重发阈值。报警引擎产生 Warning 提醒；严重状态和通信失效仍按相应安全门禁处理。

Web 车辆表、大屏和车辆详情分别显示受阻等待、持续受阻、采样失效和安全暂停。时长来自后台有效采样，不由浏览器外推；解除观察不代表任务继续或完成。旧后台未提供诊断时显示时长未知。不会因位置偏移或已发送导航而显示已验证自主绕障。

## 协议依据和能力边界

已按当前 `SEER_Wiki_Tree-refresh-manifest.json` 逐文件核对 467 个文件 SHA256，零差异。保留档案存在远程图片、附件和空表格缺项的原有说明。

- 本地正文 `02_指定路径导航.md` 的导航说明明确沿下发序列导航，不再自主规划路径。
- 本地正文 `06_查询机器人的被阻挡状态.md` 记录 blocked、block_reason、障碍坐标和 slowed 字段。这些字段不能证明本车固件已启用局部绕行。
- 本次没有修改导航模式、车端避障参数或开发新的轨迹控制器；没有连接实车验证绕行。

当前交付能力为受阻识别、等待、连续观察、原任务恢复核验及严重状态优先。车端能否在宽通道生成局部绕行轨迹、是否自动回归地图路线，仍需现场原始局部轨迹与实际运动证据。后台自动取消并寻找替代道路未启用；这一行为需要独立的道路可达性、取消确认、停止证据及资源交接设计。

## 验证

本次使用独立工作树、临时数据库和 loopback 协议模拟。与本次同时开发的充电功能不纳入本次候选包。

- `tools/ObstacleSafetySmokeTest`：状态策略、连续计时、失效与乱序、新命令门禁、两车完成隔离、资源保留、解除后原任务推进以及零取消/重发。
- `tools/ObstacleObservationSmokeTest`：短暂受阻、30秒边界、52200单独出现、严重状态优先、失效/未来采样、未知字段和解除语义。
- 单车、多车原有 smoke 及 Web 单元测试、类型检查、生产构建用于检查兼容性。

验证结果：ObstacleSafetySmokeTest 51项、ObstacleObservationSmokeTest 13项、BusinessRunSmokeTest 96项（另含23项动作反馈证据核验）、FleetTestSmokeTest 199项、MapTransferLedgerSmokeTest 55项、Web 185项通过；前端类型检查和生产构建通过。地图传输回归修正了旧测试夹具未开启缓存采样的问题，仅对内存状态启用，不建立设备连接。软件模拟通过不代表实车避障安全验收。

## 现场验收记录

现场按原任务ID、厂家任务ID、站点链、采样时间质量、速度、PLC和路权记录连续证据。建议使用厂家认可的测试障碍物和受控测试方法。

| 场景 | 预期 | 实测与证据 |
| --- | --- | --- |
| 障碍停留1–3秒后移除 | 原任务不假完成；由后续任务状态和实际运动证明自动恢复 | 待测 |
| 障碍持续30秒以上 | 持续受阻提示；保留原任务及路权；其他不冲突车辆继续 | 待测 |

| 窄通道障碍 | 停车等待，不强行通过 | 待测 |
| 绕行中触发保护停车 | 按厂家认可方法验证停车优先，保留原任务 | 待测 |
| 受阻叠加急停/Fatal/其他Error | 严重状态优先，相关流程按恢复门禁核对 | 待测 |
| 受阻期间断连或采样过期 | 当前状态转未知；恢复采样后重新观察 | 待测 |
