# 车端站点选择与3051单次导航（2026-10-23）

## 功能与使用

工程工具 → 单次导航测试（`/#/navigation-test`）现支持读取车端当前地图中的站点、下拉选择起终点、预览含中间站点的可达路线、手动确认后发送一次导航，以及原任务状态和终点位置核对。不涉及PLC点位、取放箱动作或自动派发。

1. 厂家设置车端测试速度，并确认整条路线的现场条件。使用已有 `Start-Field-Navigation-Test.cmd`，或指定测试车运行 `Start-Navigation-Test.cmd AGV-01`。通信配置仍须有效，启动不会下发导航。
2. 进入页面自动读取当前车端站点。起点优先建议为与车辆观测位置相符的站点；不能据此跳过发送前的实时核验。可手动选择地图中其他站点，但车辆不在该起点时会拒绝导航。
3. 选择不同的终点，点击核验。允许通过中间站点，要求车端1303返回从起点到终点的有效站点序列；不可达、未知站点、重复站点、首末不匹配等均拒绝。
4. 核验显示完整站点顺序，勾选整条测试路线区域确认，再发送一次导航。预览是查询时的车端规划结果，实际行驶由车端执行，不承诺强制经过某条特定曲线或锁定中间站点。
5. 页面每3秒查询原任务，展示原编号、运行/暂停/不确定状态及带时间戳的车辆站点和坐标。到点后重新读取站点，会将新观测站点建议为下一次起点；不会自动发送返程。

发送仍要求：指定单台测试车、单次导航和AGV动作许可开启，任务创建/自动派发/Outbox/步骤/PLC握手显式关闭，无活动业务任务，车辆静止、未充电、无急停阻挡和严重报警，定位置信度至少0.5，距起点不超过0.25米，控制权明确未占用。不得靠3051覆盖其他尚未结束的任务。

启动恢复、地图切换和地图传输门禁继续有效。门禁关闭时可以只读取得站点，不能核验放行或发送导航。当前Web如关闭恢复处置，应通过具有恢复权限的客户端完成当前批次现场核对；本功能不自动确认或解除恢复屏障。

## 协议与数据

依据现有官方本地档案 README、刷新清单和正文，不重新抓取协议。实际读取并与刷新清单核对SHA256一致的正文：

- `docs/vendor/robokit/SEER_Wiki_Tree/API/TCP_IP_API/机器人导航API/01_路径导航.md`：3051给定目标、车端规划、经过中间站点，适用于单车验证；新任务会取代未完成任务，因此保留严格空闲检查。
- 同目录机器人状态API的 `33_查询机器人当前载入地图中的站点信息.md`：1301站点及世界坐标。
- 同目录机器人状态API的 `35_查询任意两点之间的路径.md`：1303的source_id/target_id与list。

新增只读Web接口 `GET /api/navigation-test/stations` → Named Pipe `GetNavigationTestStations` → 主服务1300/1301/1100/1110/1300/1022查询。站点目录绑定地图名、MD5和读取时间；核验请求携带目录来源身份，车端地图变化后须重读目录。Web本身不连接机器人。

核验后提交会再次检查地图、路线序列、终点坐标和车辆状态；核验令牌有效30秒且仅能使用一次。所有运动发送前，将唯一编号、地图身份、起终点、完整核验路线、目标坐标、协议类型和发送意图持久化并Flush。

仅该独立单车入口改用3051，载荷只有source_id、id和唯一task_id，不附带operation或速度覆盖，不逐个中间点反复下发。正式业务调度链的3066方式保持原样。

收到ret_code=0仅表示应答接受。只有按原task_id查询到完成，所有车端任务处于终态、车辆静止，当前地图身份一致、加载完成，且置信度至少0.5、车辆距记录终点不超过0.25米，才显示完成。否则保持不确定并阻止新测试。时间戳区分最近查询和最近成功车辆观测，旧观测不冒充实时位置。

超时、断线、缺失应答或后台重启后保留意图，只查询原编号，不重试3051。没有查询到原任务不表示没有发送。取消仍按原任务编号定向3003，继续查询终态和静止状态；协议取消不是急停。历史3066记录按原编号继续查询，缺失的目标坐标从身份核对通过的当前车端地图恢复，不重发导航。

## 验证

- 新增 `dotnet run --project tools/NavigationRouteSmokeTest -c Release`：43项本机TCP模拟检查，含站点读取、地图变化、跨中间站点、无效路线、发送前变化、唯一一次3051、原任务回查、定位/位置/运动/地图不符、定向取消、历史3066兼容及重启无重发。
- `SingleNavigationTestSmokeTest`：当前工作区59项回归通过，含既有地图导入和只读下载；未传入现场文件，不能沿用此前含现场输入的64项计数。
- Web122项测试、类型检查和生产构建通过；Service与WebHost Release编译通过。
- `npm run test:navigation-browser`：12项浏览器交互检查通过，使用独立本机HTTP模拟接口。检查阻塞原因、站点选择、完整路线、显式确认、改站撤销核验、仅一次提交、运行时锁定选择、到点后再次选择、窄屏及查询失败显示。截图与结果仅保存在本地 `artifacts/navigation-browser/`。

这些结果证明软件逻辑与模拟通信流程，不证明当前现场固件已接受3051、真实路径完全符合预览或实车到点验收。实车验证仍须厂家在场，由用户核验并明确确认后下发。
