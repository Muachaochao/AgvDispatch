## 算法和后台

NearestAssigner 按当前节点到取货节点的欧氏距离选任务。GreedyEtaAssigner 用 A* 估计空驶与送达的道路耗时。SimulationEngine 使用 100 ms tick，默认每次装卸 5 tick、等待 30 tick 触发重规划、最大 200000 tick。ReservationTable 以节点或弧 ID 保存逐段滚动的时间区间预约。节点与弧的容量语义由算法模型定义。

Spring Boot 负责路网和任务集 CRUD、每用户仿真实例、WebSocket 帧、实验历史、认证和审计，H2 文件库可独立运行。前端使用 /api/sim/*、/api/roadnet/*、/api/taskset/*、/api/experiment/* 与 /ws/sim。makespan 与 totalWaitTick 使用实验 tick，totalPathLen 使用米。

## 当前全厂地图验证

现有工程仿真图包含 1112 个节点和 1887 条道路，其中 29 个 WaitingPoint 和 2 个 ChargingPoint。原图存在同端点正反向道路，原模板会报告 DUP_EDGE_PAIR。原图包含单向 CAD 尾点，原模板会报告 DEAD_END。WaitingPoint 直接转换为 BUFFER 会触发原模板 BUFFER_NOT_LEAF。

适配器为平行道路生成独立中间节点，保留方向与原边映射。通行候车点映射为 JUNCTION 并列入转换提示。启用初始点可往返分量后排除 4 个节点和 8 条道路，生成 2178 个实验节点、2949 条实验路段，原 Java 校验器返回 0 条错误。已将该副本保存到独立 H2，名称为“现有全厂仿真图 · 算法实验副本”。完整原定义和转换记录留在本地 .runtime/current-map-import.json，现场输入未提交到 Git。
