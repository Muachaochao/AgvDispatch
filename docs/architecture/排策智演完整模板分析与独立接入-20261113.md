## 算法和后台

NearestAssigner 按当前节点到取货节点的欧氏距离选任务。GreedyEtaAssigner 用 A* 估计空驶与送达的道路耗时。SimulationEngine 使用 100 ms tick，默认每次装卸 5 tick、等待 30 tick 触发重规划、最大 200000 tick。ReservationTable 以节点或弧 ID 保存逐段滚动的时间区间预约。节点与弧的容量语义由算法模型定义。

Spring Boot 负责路网和任务集 CRUD、每用户仿真实例、WebSocket 帧、实验历史、认证和审计，H2 文件库可独立运行。前端使用 /api/sim/*、/api/roadnet/*、/api/taskset/*、/api/experiment/* 与 /ws/sim。makespan 与 totalWaitTick 使用实验 tick，totalPathLen 使用米。

## 当前 Web 仿真地图验证

主工程 `/api/simulation` 当前绑定 B07 “305CNC·现场双线终端修订”，方案为“B07-1F·305工位·5车·200单·双行线·安全停点v3·0.75m/s”。来源地图包含1112个节点、1887条有向道路、1641个资源、305个PLC工位和5台虚拟车。775个普通路径点显式禁止停车，337个业务或安全停点显式允许停车。

独立模块直接读取同一实例地图，转换后保存为“全厂五车仿真”。双向道路合并为1352条实验道路，排除4个不可往返死端节点及8条关联道路后，保存1108个节点、1344条实验道路，校验错误为0。编辑页同时展示主工程来源1112节点、1887道路和305工位，并直接采用主工程地图摘要`CDE05EFC…`。原任务集继续保留，任务端点均存在于新地图。

当导入图节点超过30个时，只读预览保留原模板的浅色网格、左下角图例和右上角概览面板，并隐藏中间分段、路口编号、CAD参考点红框和文字。等待区使用绿色圆角轮廓，倒料区使用青色圆角轮廓，充电区使用紫色圆角轮廓，分别显示“等待区”“倒料区”“充电区”。三个区域使用独立且不相交的边界，不再显示“铝屑终端处理与倒料区”总标题。充电区轮廓完整包含两个充电位。搜索、选择、悬停和属性查看仍能定位全部节点、路段和参考点。

B07 三维预览使用大图精简模式，缩小1108个实验节点模型，隐藏方向箭头和普通节点标签，只保留必要设施标签，避免总览被数千个标签遮挡。

道路简化默认启用，曲线道路在实验副本中画为起终点直线，保留原长度、速度和方向。B07 源图有成对反方向道路，导入器将长度、速度和资源一致的两条道路合并为一条双向道路，两个源 ID 均写入映射记录。

Web 仿真已切换到保存方案“B07-1F·305工位·5车·200单·双行线·安全停点v3·0.75m/s”。当前实例绑定最新 B07 双线终端修订版，5台虚拟车按0.75m/s现场基准运行。导入器合并端点相反、长度和速度一致的有向道路，并保留两个源 ID。

此前导入的“全厂五车仿真”及旧全厂副本属于错误来源，已从独立后台清理。转换记录保留在本地 `.runtime`，现场输入未提交到 Git。
