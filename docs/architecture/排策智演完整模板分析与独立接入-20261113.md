## 算法和后台

NearestAssigner 按当前节点到取货节点的欧氏距离选任务。GreedyEtaAssigner 用 A* 估计空驶与送达的道路耗时。SimulationEngine 使用 100 ms tick，默认每次装卸 5 tick、等待 30 tick 触发重规划、最大 200000 tick。ReservationTable 以节点或弧 ID 保存逐段滚动的时间区间预约。节点与弧的容量语义由算法模型定义。

Spring Boot 负责路网和任务集 CRUD、每用户仿真实例、WebSocket 帧、实验历史、认证和审计，H2 文件库可独立运行。前端使用 /api/sim/*、/api/roadnet/*、/api/taskset/*、/api/experiment/* 与 /ws/sim。makespan 与 totalWaitTick 使用实验 tick，totalPathLen 使用米。
