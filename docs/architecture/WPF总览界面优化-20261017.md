# WPF 总览界面优化（2026-10-17）

本轮从当前 WPF 总览入手，沿用现有工业蓝配色、地图优先布局、浅深主题及车辆面板收起行为。

- 运行地图标题下显示 ViewModel 已有的四项统计：在线车辆、等待调度、执行中任务、异常任务；未连接时显示未知值。
- 参数标签提高到 12 DIP，车辆选择采用主题色边框和背景，车辆电量使用正文色，车辆面板按钮提供键盘焦点提示。
- 图例与刷新信息分别换行；任务区高度随可用空间在 140–180 DIP 之间变化，为小窗口保留更多地图空间。
- 无地图时使用居中说明；无活动任务和后台断连使用不同文案，断连时隐藏任务数量，车辆区域提示状态不可用。
- 任务阶段复用任务中心的 `TaskLabelConverter`，表格复用 `AppDataGridStyle`。

## 验证

在 DispatchingSystem 目录执行：

```powershell
dotnet run --project tools/DashboardUiSmokeTest --artifacts-path .artifacts/ui-polish -p:NuGetAudit=false -m:1
```

回归覆盖原有运行地图版本、缓存、选择、过期位置和坐标单位保护，另覆盖任务空状态与非空状态、断连与恢复、浅深主题渲染和紧凑布局下参数滚动到底部。

截图位于 `docs/screenshots/wpf-overview-20261017/`，包含改前 `before-live.png` 与改后 `live.png`，以及紧凑、深色、无地图、断连和有任务状态。

截图来自真实 WPF 控件的 RenderTargetBitmap 渲染，数据由隔离的合成夹具提供。922×668 DIP 是从最小 1180×720 DIP 主窗口扣除展开导航和页眉后计算的页面尺寸。该验证没有连接 AGV/PLC，也不代表实车、现场显示器 DPI 或完整主窗口交互验收。深色截图采用新建视图解析主题资源，不作为运行中切换主题的验证。
