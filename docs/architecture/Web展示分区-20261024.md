# Web 展示分区

入口：工程工具 → 工程编辑 → 展示区域；也可打开 `/#/planning?tab=areas`。

选择后台地图并读取分区。正在运行的地图使用当前运行版本；其他地图使用已发布版本，没有发布版本时使用草稿。机器人拉取后尚未保存的临时预览不作为持久分区的归属，需先保存为后台地图。

新增区域支持拖动矩形，以及逐点绘制多边形（双击、Enter 或完成按钮结束）。首次完成边界时建议选择边界内及边界上的站点，之后可手动勾选；调整顶点不会自动覆盖已确认的归属。也可显式点击“按当前边界重新选择站点”。同一站点允许关联多个展示区域。

可编辑名称、颜色、名称与边界显示开关，拖动白色顶点修改形状。删除仅移除标注，保存后生效。切换工作台模块会保留当前编辑内容；离开路由或关闭页面时提示未保存修改。重新读取会要求确认丢弃本页未保存内容。

点击“保存展示分区”，保存到 Web 后台工程方案目录旁的 `display-areas`。日常为 `发布包/运行数据/display-areas`，不是浏览器 localStorage。备份运行数据时一并备份该目录。地图草稿、运行版本、车端地图、道路资源、导航与 PLC 均不写入。

大屏每5秒读取当前地图分区，2D和3D使用相同淡色多边形；站点、车辆标签优先避让。点击区域名称或区域底色查看所属站点，底部区域列表也可查看被遮挡或关闭名称的区域。

存储使用原子替换和版本校验；其他页面已保存时，旧页面收到409，不覆盖新版本。更换地图ID不会共用分区；站点与坐标基准变化时暂停叠加，需重新读取、核对边界与站点后保存。边界自相交、面积为零、未知站点、重复编号及非法颜色由后台拒绝。

验证：DisplayAreasSmokeTest 包含13项持久化、冲突及输入校验，另有2项发布版本识别回归；前端合并当前厂家区域标注修复后142项通过；`scripts/display-areas-browser-check.mjs` 在关闭设备通信的 WebLayoutFixture 中14项检查通过，涵盖绘制、保存、刷新、顶点拖动、手动站点关联、删除以及大屏2D/3D显示。脚本拒绝5199/5198日常端口，不在现场数据库写入合成区域。

部署时发现当前程序集版本带 .NET 自动追加的 `+40位Git提交号`，原启动器按整串比较发布编号而拒绝启动。启动器现接受相同批次编号及合法40位十六进制Git构建后缀；不同批次及无效后缀仍拒绝。端口、管道、工程存储和进程归属校验均保留。2026-10-24更新仅复制Web接入和静态页面，未替换本次部署前的Service文件；恢复5199后核对原地图ID、版本、4节点/10道路及分区API。原Web文件备份于发布包/升级备份/display-areas-20261024-121518。
