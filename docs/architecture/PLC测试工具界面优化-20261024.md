# PLC测试工具1.4.0界面优化

用户要求核心10点固定显示、P/H分区、阶段操作与等待指导、28阶段进度/失败筛选及日志分类。本次仅修改独立工具的展示和只读投影，不修改主调度、S7协议、自动许可/恢复门禁或现场写入权限。

## 三个主要操作步骤

1. 人工联调：4个P点与6个H点分区，H不显示写入按钮。地址、当前内存、参考值、新鲜度同屏，故障/下游在线独立折叠并持续显示摘要。短窗口压缩行高，故障区自身滚动；未启动显示未知实际值。右侧突出P操作与H等待，现场观察和说明折叠。
2. 阶段结果：28格颜色配合结果文字提示，进度按本轮有记录的阶段去重计数，失败/跳过不算通过。可筛选失败行，28格和总统计不受筛选影响。点击阶段仅切换只读查看对象，不切换人工标记、不写点位和日志。10点对照标明当前内存、参考值、差异及交换质量；保存时结果另行显示，保留原观察和快照，阶段22允许双值。
3. 会话日志：独立页显示全部、业务、通信、异常和显示数量，主操作面板有直达入口。业务/通信与异常可重叠，界面只筛选最近500条，JSONL及全量导出不受影响。
