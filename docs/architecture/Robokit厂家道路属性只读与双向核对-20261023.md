# Robokit 厂家道路属性只读与双向核对

日期：2026-10-23。范围：Web 工程编辑中的厂家道路来源查看、调度参数对照及原图留存。此批不修改车辆参数，不上传厂家地图，不激活运行地图。

## 使用方法

1. 在 Web 工程工作台关联后台，通过既有 SMAP 导入入口导入原文件，再打开该地图草稿。
2. 在画布或道路对象列表选择道路，右侧出现“厂家道路原始属性”；点击“查看厂家属性／双向核对”。重叠道路可以通过对象列表分别选择。
3. 查看厂家起终点、原曲线序号、类型、原文件与二维部分 SHA256，以及当前调度端点、方向、限速。调度限速与厂家 `maxspeed` 分开显示，导入不会把后者自动写入调度参数。
4. 弹窗按运动、到点与载荷、传感器与避障分组显示字段名、原类型、原值、原条目。反向道路按同一来源及交换后的厂家站点编号查找；存在多个候选时单独选择，不合并参数。
5. 正反向差异就近显示。`direction` 的正走／倒走不是调度道路的单向／双向；没有反向记录也不表示反向参数相同。
6. 点击“下载后台留存的原SMAP”可取回本次上传的原字节。保存草稿、方案 JSON 导出及重新读取保留来源属性。原文件单独存放在该 Web 后台配置目录对应的 `vendor-map-sources` 中；跨电脑复制方案 JSON 不会附带原文件，另一后台缺少原文件会明确提示。

已有旧草稿没有这些证据，需要重新导入原 SMAP，不能从当前调度值补造厂家参数。WPF 的直接打开 SMAP 入口未在本批新增属性面板。

## 三种状态

| 状态 | 含义 | 示例 |
| --- | --- | --- |
| 未设置 | 有可识别属性证据，但该字段未出现 | 没有 `maxspeed` 条目；车端继承值仍未知 |
| 显式设置 | 原类型与对应值可识别 | `laser=false`、`StopAcc=0` 均保留，不显示为未设置 |
| 未知 | 证据缺失、属性结构异常、重复字段或类型不支持 | 仅有 `value` 编码而没有对应类型值，不猜测解码 |

识别 28 个常见名称：`direction`、`movestyle`、`mainroad`、`maxspeed`、`maxacc`、`maxdec`、`maxrot`、`maxrotacc`、`maxrotdec`、`reachangle`、`relaxGoalReachDist`、`width`、`length`、`holdDir`、`loadHoldDir`、`unLoadHoldDir`、`forbiddenRotAngle`、`StopAcc`、`ultrasonic`、`laser`、`fallingdown`、`infrared`、`virtualLaser`、`3DCameraHole`、`3DCameraObstacle`、`collisionGroupId`、`forbidLaserGroupId`、`forbidDNodeGroupId`。其他字段也原样保留，包括仅反向存在的字段。

中文标签用于查阅，不代表本车固件语义、单位或默认值已经核定。未知枚举不强行解释，不能依据某个传感器字段值认定现场安全功能已经启停。

## 来源和差异边界

- 每条道路绑定原始 `advancedCurveList` 序号，跳过不支持的曲线后也不会错配后续属性；显示原始曲线数与已转换数，不能把部分转换称为完整副本。
- 本批支持既有直线、Bezier、DegenerateBezier 导入对应记录；不扩展 ArcPath 几何解析。
- 原文件和包内二维字节分别计算摘要；下载前复核原文件大小和摘要，同摘要重复导入幂等留存，损坏原图不静默覆盖。
- 修改道路编号、端点、厂家站点绑定、坐标、曲线控制点或几何类型后，原属性仍保留，但提示“原图历史属性”，不声称已经适用于新道路。
- 厂家原属性和整图来源变化进入地图版本差异；旧图空证据不增加 JSON 字段，避免无故改变旧定义摘要。
- 任意导入 JSON 自带的来源标签不构成真实性证明；需取回留存原图复核。当前视图也不能证明车端正在使用同一图，仍需实际版本／MD5 和只读返回核验。
- 属性每曲线最多 512 项、64 Ki 字符，合计原文 UTF8 最多 2 MiB；原 SMAP 归档最多 8 MiB。超限明确拒绝，不静默截断。
