# Web车辆连接管理

车辆列表提供逐车“连接通信／断开通信”。连接启动只读采集，不直接发送导航、顶升或下降；启用后是否在线、能否派车仍由实时状态及原有执行门禁判断。断开会关闭状态和导航通道并停止自动重连，保留车辆、地图绑定和历史任务，禁用状态保存到原通信配置文件，重启后继续保持。

操作路径：5199 → 车辆列表 → 对应行的连接通信／断开通信。启用但尚未连通时显示断开按钮，表示停止这台车的连接尝试，不能把按钮文字当成在线证据。请求期间禁止重复点击，响应不确定时只重读状态。已保存但尚未重启的拓扑配置阻止即时切换，避免对旧IP操作。

权限、配置版本和地图切换互斥由后台核对。该车有原业务运行、双车测试或未结束任务，以及存在尚未分配车辆的任务时，需先处理原责任。独立导航／升降模式中的测试车不能使用此入口切断监控；必须先结束原测试并退出模式。在线车辆断开前实时核对停稳和原车端任务列表。断开不是急停，不释放路权，不取消原任务，也不批准恢复。

新增、删除、改编号、IP、端口及总采集开关仍走“新增／配置车辆”，保存后受控重启。即时按钮只对本次后台已加载的车辆生效，包括启动时停用的车辆；不能隐式加载待重启的新地址。所有车均断开后，轮询服务保持待命，重启后仍可由页面逐台连接。

发布升级保留现场双车启动脚本的车辆组合，避免把其他用途的AGV-02错误改回双车范围。

验证：通信设置隔离测试覆盖即时保存、权限、旧版本拒绝、任务保护、逐车隔离、全断开后重启配置有效和迟到采样隔离；分端口TCP模型覆盖真实连接关闭、断开后控制报文拒绝及重连不重放导航。单车导航和双车Outbox回归通过。上述模型验证不等于现场运动验收。

同类配置现状：车辆地址、PLC点表、工位站点映射和地图资源已有配置入口；车辆尺寸／最大载荷包络、出区定位阈值以及双车运行范围和独立测试模式还需要进一步集中到Web配置流程。运行模式涉及发送权限与原责任，不能仅靠通信按钮隐式切换。
