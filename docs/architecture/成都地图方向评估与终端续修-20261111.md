# 成都地图方向与终端续修（2026-11-11）

以用户最新两张方向标注为依据，只构建地图并静态评估，未运行仿真、未连接真车/PLC、未激活日常5199方案。此版替代同日首版的底部横段和处置支线设计。

## 采用方案

六组横向主线保持上排向东、下排向西。各换道短段保留上下双向许可，反向边共享容量1资源，各交叉口共享节点；它们不是双车并行车道。工位进退支线也双向互斥，工位泊位不得当穿行捷径。方向限制不等于控制器实际允许相应转弯，仍需完整转弯包络检查。

终端西侧进区、东侧返回。底部横段改成只向东，避免返回车辆逆向钻回进区线。待命中间横道双向互斥，五泊位保持三上两下。删除图中用户划掉的西侧处置点及支线，不把未测绘点当安全站点；软件检修引用暂复用WAIT-01，不代表可自动把事故车辆移到此处。

倒料西侧短支线约0.902m，设计进入设备对接后原路倒退至返回竖线，再向北返回。地图已保留相反方向边及共同路权；车端倒退动作未在本轮验证。对接朝向、载荷包络、车端原任务终态、倒退通道及出口交叉口占有均须满足后才能执行。不可把“退回返回线”误写为小车自行完成避障。

两个充电位保留独立支线，充电不穿待命泊位，但充电进出仍使用主通道接入交叉口，不能声称完全不影响空箱返程。后续运行策略应避免在返回车即将通过时抢占出口；本轮没有修改派车或交通运行算法。

## 同一几何下的静态方案比较

从倒料点、WAIT-05各到305个CNC，共610条路线，统计允许方向下最短路长度。平均值仅用于这组固定起终点比较，不是吞吐量。另对305项单工位占道绕行逐项检查，排除实际占用资源，不只检查空地图可达。

| 换道方向 | 305项占道绕行失败数 | 610条路线平均长度 | 最大长度 |
|---|---:|---:|---:|
| 受控双向（采用） | 0 | 110.200m | 167.681m |
| 全部上→下 | 127 | 131.770m | 225.084m |
| 全部下→上 | 0 | 117.797m | 209.122m |
| 沿X方向交替单向 | 60 | 112.253m | 173.931m |

四组空地图均610/610可达，但单向方案在占道时可能失去绕行路径。当前采用方案在本次比较中同时保持全部占道绕行通过和较短路径；尚不能据此宣称动态多车场景的全局最优或绝无死锁。

## 检查结果及边界

12项地图单元测试通过，新增核验双向换道/倒料支线共用容量1资源、底部横段无反向边、倒料可退出以及无虚构处置支线。4270项静态有向可达、15项其余四车停放时的待命离位检查通过；305项占道绕行及CNC-209占道到CNC-233回归通过。

当前为1088节点、1864有向边、1619资源。仍保留540条CNC近侧停靠包络与道路相交记录，已有资源保护但全厂净空总审查仍未通过；未放宽几何检查。下排待命位至设备轮廓的纵向余量、车体旋转扫掠、满载箱体尺寸和充电/倒料对接姿态仍需核定。当前地图不作为实车可下发导航。
