# 站点标签与任务历史查询优化

## 已调整

- 大屏站点标签改为贴近真实站点的小文字标注，车辆标签保持突出。自动模式避免文字重叠，密集时收起次要标签，放大地图后自动显示；悬停站点附近可优先显示。短引线最长48像素，不再将标签抛到地图外侧。
- 大屏地图右上角可切换“标签·自动／全部站点／隐藏站点”。全部模式保留全部编号，极密集时可能重叠，建议放大；隐藏模式仍保留车辆标签。不会移动站点、更改道路或改变车辆导航。
- 业务阶段环图读取后台数据库的全量分组统计，覆盖历史全部记录，与分页大小无关。“已取消”独立统计，不再混入异常。后台未返回完整统计时明确显示暂不可用，不以当前50条代替全部。
- 大屏“当前任务”仅显示未结束任务；历史完成和取消记录进入业务任务页查看。
- 业务任务页统一查询后台分页数据，增加创建时间开始／结束控件、今天／昨天／近7天／全部时间快捷按钮。时间使用浏览器本机时间，传输时携带明确时间偏移；数据库按原保存时区转换。范围含开始、不含结束时刻，因此查询某天应选当天00:00至次日00:00。
- 可选择每页20／50／100／200条，显示总数、当前记录区间和总页数。总量没有50条上限，超过一页可继续翻页。
- 时间、状态、关键词和每页条数共同作用于同一查询。修改条件后标为待应用，翻页沿用已应用条件，避免无意改变结果范围；错误保留原结果并显示错误，空结果明确显示0条。
