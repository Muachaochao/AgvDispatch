# WPF 全界面统一优化与编译（2026-10-17）

## 范围与效果

沿用已确认的工业蓝风格和现有 WPF/HandyControl 控件体系，对当前客户端进行一轮统一优化。覆盖主窗口导航、总览、任务中心、AGV 管理、设备监控、交通资源、通信诊断、报警、现场恢复、通信设置、地图管理、地图编辑器、新建地图和三维点云工具栏。

- 表格统一表头字重、横线、单元格留白、省略与全文提示、选中状态和键盘焦点；保留专用状态列及编辑列的原有绑定。
- 页面标题、说明与操作工具栏分行，任务查询区支持换行；设备搜索增加可见提示和辅助名称。
- 地图列表、编辑器面板和新建地图移除局部强制浅色资源，跟随应用主题。CAD 绘图画布继续使用既有浅色背景和图元配色；三维视口继续使用深色背景。
- 现场恢复移除固定浅色按钮与文本，采用公共主题控件；报警、错误和注意信息使用语义画刷。
- 新建地图窗口支持调整尺寸，表单内容可滚动；三维高度输入补充辅助名称。
- 延续前一轮总览优化：四项统计、车辆选择、未知状态和无任务状态区分。

本轮主要修改 XAML 和公共样式，未改变现场写入命令、许可条件、协议或后台业务流程。工作区原有其他开发改动保留。编译输出包含当前工作区源码。

## 文件与复现

- 客户端可启动输出：`artifacts/WpfUi_20261017/AgvDispatch.Wpf.exe`。
- 这是 win-x64、依赖框架的客户端，需要 .NET 10 Windows Desktop Runtime；后台服务仍按当前项目方式独立启动。
- 页面截图：`docs/screenshots/wpf-full-20261017/`。
- 构建与回归日志副本：`docs/evidence/wpf-full-20261017/`。
- 完整输出目录需整体保留，不能只复制 EXE。

```powershell
dotnet run --project tools/FullUiSmokeTest --artifacts-path .artifacts/ui-polish -p:NuGetAudit=false -m:1
dotnet build AgvDispatch.sln -c Release --artifacts-path .artifacts/ui-polish -p:NuGetAudit=false -m:1
dotnet publish AgvDispatch.Wpf/AgvDispatch.Wpf.csproj -c Release -r win-x64 --self-contained false --artifacts-path .artifacts/ui-polish -p:NuGetAudit=false -m:1 -o artifacts/WpfUi_20261017
```
