# Web中央地图联动与取消恢复演练

更新：2026-10-18。当前快捷AGV采用Robokit TCP，沿用C# Service原任务、取消及恢复逻辑。

## 真实后台的中央地图

调度大屏下方新增“联动任务”。选择任务后读取原任务详情及原路权生命周期，显示：

- 绿色道路：经过归属、地图ID/版本/内容摘要核验的原命令路线；不是重新计算的最短路，也不代表命令仍在执行。
- 橙色资源：该任务在当前地图版本上实际持有的资源。
- 红色资源及红圈车辆：后台明确返回的当前阻塞资源和阻塞车辆。点击阻塞车辆编号，左栏切换车辆详情。没有核定坐标或位置过期时只列编号，不从站点或路线端点补车位。
- 绿色车辆圈：所选任务车辆；车体原来的状态颜色保留。所选普通车辆为浅色圈。

联动任务选择空项可取消高亮；“查看步骤与处置”打开原九步、PLC条件、取消进度及恢复入口。切换任务时清掉旧详情，断连、诊断过期或旧响应不再作为当前联动。道路搜索独立保留，原任务路线优先显示绿色。

资源只按同地图ID/版本的路权记录关联，不根据路线相交猜阻塞。旧/缺失地图归属不贴当前图；过期租约仍可能保留占用，不能按心跳超时自行放行。路权最多返回200条且可能截断，页面明确提示，不能当作全场完整查询。未返回当前阻塞不等于已经满足派发条件。

原导航图仍不是厂家激光底图或原生三维点云。地图范围计算纳入道路采样及资源边界，避免弯曲道路被节点范围裁切。

## 八阶段浏览器演练

1. 使用根发布包“启动最新版Web.cmd”，打开“调度大屏”，点击顶部“演示模式”。
2. 点击黄色演练面板“开始 / 重置演练”。此后手动推进，不按原九步定时器自动换阶段。
3. 联动任务选`DEMO-TASK-002`：查看`SHARED-01`红色区域、阻塞车`AGV-01`。选择`DEMO-TASK-001`：查看原路线和持有资源。
4. 依次点“下一阶段（模拟）”：取消意图记录 → 3003接受但等待1110 → 1110确认结束。前四阶段仍保留原占用，车辆终结不会自动释放资源。
5. 进入恢复核对阶段，勾选四项模拟确认：停车位置、箱体归属、原PLC周期、原路权处置依据。少任一项不能继续。
6. “模拟核对并处置占用”明确模拟现场处置；此后橙色持有资源才消失。它不是车辆结束回执自动释放。
7. “模拟关闭取消”：任务标为取消，不能将九步补成全部完成。
8. “模拟全场核对放行”：只演示恢复批次放行，不启用通信、不派新车。可重置重看；“退出演示”回到真实后台并清理合成任务选择。

全部演练数值、确认和车辆位置为浏览器内合成教学，不调用任务取消、恢复、PLC或AGV控制接口。它不是一次真实Service驱动的完整现场执行；协议、恢复后端和界面分别验证。无后台启动也可看演示，但软件静态页面仍需本机WebHost提供。

## 真实取消与恢复

真实任务详情中的“申请取消任务”沿原后台校验，Web任务操作开关默认关闭。请求携带`expectedStage`、原任务编号、原因和申请编号。旧`currentStage`字段或缺少预期阶段明确拒绝，不默认为Created。响应不明时同一浏览器session保留原意图编号，必须先刷新原任务，不换参数补发；不同浏览器/会话自动找回不在本批范围。

取消详情区分请求记录、发送尝试、发送时间和原运输结束确认。3003接受不等于车已停，1110结束不等于载荷、PLC和路权均可清理。CancellationPending不能提前进入恢复处置。恢复会冻结全场后续执行；确认后仍需原后台逐项核验、路权处置及全场放行，不提供强制跳步或直接写PLC位。

根固定启动入口继续强制关闭设备通信、执行、Web提交和恢复写入，不能通过演练开启。真实字段、Roboshop地图/坐标及厂家部分接收、重复编号、取消级联规则仍需本车资料核定。
