# 滚动全局派车验证记录（2026-11-03）

本次依据用户确认的滚动窗口全局优化方案实现，协议继续采用快捷 AGV / Robokit TCP。操作与参数说明见 [滚动全局派车与影子比对](dispatch-rolling-optimization.md)。

## 实现及验证

默认 `Shadow`，每 3000ms 计算当前最紧急 80 个等待任务，按车辆池、健康、电量、定位、路径及责任门禁建立候选，再做最小费用最大流。每车默认保留 15 条、每任务保留 2 条，并修复裁剪造成的可行匹配损失。已派发或持有路权的任务、车辆不重新分配。全局模式需要管理员在界面保存策略后启用，原有业务执行、PLC 与启动恢复门禁继续有效。
