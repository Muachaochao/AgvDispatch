# Web操作按钮图标约定

本批沿用现有Tabler线形图标，为工程工作台、服务端方案库、地图管理、工程配置、任务/车辆/告警列表及大屏部分操作补充图标。

- 保存用磁盘，导出用向下箭头，加载用向上箭头；发布用云上传，与导出区分。
- 预览/详情用眼睛，版本用历史，删除/移出用垃圾桶，编辑用笔，定位用地图点。
- 工程模块、绘图工具和属性面板使用明确的图标映射；编号、统计和状态不自动添加图标。
- 统一新增图标为14px、1.7线宽、不被挤压；保留文字名称。SVG设置aria-hidden及不可聚焦，避免重复朗读。
- 原有按钮事件、权限、禁用条件、确认流程及提示文字不变；灰色按钮的图标同样跟随禁用样式。
- 编辑器窄侧栏的属性/批量/图层/历史采用两列布局，避免图标增加后出现不均匀换行。

本次69处静态操作补充图标，另包括五个工程模块和动态绘图工具/面板。Vue/TypeScript及Vite构建通过；一次性AST对照核对8个Vue文件的125组按钮属性，事件和禁用条件保持一致。检查脚本最初使用基础解析器遗漏HTML空元素规则，切换DOM解析器后核对通过；没有将初次脚本错误当作产品缺陷。

实际5198浏览器观察了方案库读取、模块切换、地图管理和编辑工具；1384×871、1280×720及最终测得800宽窗口未出现文档横向溢出。800宽地图操作自动换行，编辑侧栏两列坐标核对一致；这不代表所有页面在所有尺寸均已验收。控制台未观察到警告或错误。纯图标和布局变动不重复运行未变化的协议/任务测试。

按当前批次部署前端静态补丁，保留旧哈希资源及更新前备份，核对1129个原生文件和本次静态文件SHA。服务、现场配置、运行地图、切换门禁及数据库保持不变。验证没有创建任务、激活地图或向车辆/PLC发送控制。
