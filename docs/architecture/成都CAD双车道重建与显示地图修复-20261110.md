# 成都 CAD 双车道重建与显示地图修复（2026-11-10）

本批依据用户确认的 305 台 CNC、5 辆 AGV、2 个充电位和一个终端倒料设备，使用有效 CAD 及用户本轮提供的厂区、终端截图。用户授权自行设计双排道路方向与交叉连接。仅修改隔离仿真输入与显示桥接，不向现场车辆、PLC 或日常 5199 下发。

## 地图设计

- 从有效 DXF 的 843B4～843BF 十二条长横线提取六组物理分开的车道，上侧向东、下侧向西。间距按 CAD 原始毫米坐标换算，不能用同一条中心线画两次充作双车道。
- 左右外围各两条竖向车道，内外方向相反；端部、中部及满足间隙条件的工位之间设置换道口。全部平面交叉拆成共享节点，保留容量 1 的交叉口和双向支线互斥。
- 终端沿 844F7、8CB89 对应的双竖线接入五待命位、两个充电位和倒料对接支线；待命位各自接入收集道路，不借另一待命位穿行。倒料设备本体与车辆对接点分别标示。
- 保持 305 台机台中心；取箱位向最近真实 CAD 横线偏移 1.1 m。近侧道路受停车包络影响时保留对应 CNC 资源约束，不以任务完成代替物理离位。
- 当前 v3：1096 导航节点、1874 有向边、1626 资源。方向、换道口、对接支线为仿真设计；原图相关线层名为“管道”，本批依用户授权用于仿真路线参考，不称其为厂家已核定 AGV 路线。

原始截图在本机证据目录保存。厂区截图 SHA256：`A2B1F7AB5EFDE885C5CC5EA05651D8E97FDE29D6DA893DC02B1F12D43F48B8F9`；终端截图 SHA256：`C94FD608CC67DB2454BE7F6B4CD06C0D425B4A91BF5C0BA6955C2431F2AA3495`。CAD 其他源文件校验见地图产物 `source-manifest.json`。

## 截图警告的排查与修正

阅读本机已有反编译资料的 `SCanvas.SameMarkCheck`、`StationView`、属性转换及公开 API 实现，未修改第三方 DLL、认证或分析开关。

1. 参考点和分区说明曾作为无连接站点导出；改为普通文本。转换器原来不能正确读取 `OrderedDictionary`，导致参考说明坐标落到原点；已修正字典取值并加入精确坐标回归。
2. 密集换道处默认 30 像素站点符号会触发附近未连接端点检查。通过公开属性接口缩小至 2 像素，同时还原并逐点回读原世界坐标。仅改大小会造成中心点偏移，脚本不允许忽略这一问题。
3. 原中部换道口距机台接入点仅约 3.2 cm，导入可能合并并丢线；调整换道位置，避开已有连接点。

最新实际导入回读：1096 站点、1874 线路、34 普通文本、5 车。端点规则核对重叠 0、近而未连 0，坐标无超出舍入容差的变化；原软件分析 API 返回 200。此项是 API 与几何核对，不替代原生窗口人工目视验收。
