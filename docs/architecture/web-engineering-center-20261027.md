# Web 工程配置中心与隔离模拟开发报告

日期：2026-10-27。

## 本批交付

本批提供不依赖 WPF 的工程配置和展示测试入口，重点验证 300 工位、5 台车辆的配置组织与模拟预约。没有连接真实 PLC、AGV，没有升级日常 5199，也没有修改现场运行数据库或恢复发送许可。

### 统一工程配置

- Web `/engineering` 集中维护地图节点、道路、交通资源、PLC 连接与信号、车辆与包络、车辆池、工位、业务模板、倒料设备和待机位。
- 工位支持搜索、分页、复制、批量修改、CSV 导入和差异确认；未列入导入文件的工位不会被删除。支持完整工程 JSON 导入导出。
- 草稿可在设备离线时保存。修订冲突拒绝覆盖；发布生成不可变配置快照和 SHA256，历史版本可载回草稿后再修改。
- 统一校验覆盖编号、引用、点位方向和地址冲突、路径可达、车辆能力、电量、包络填写、待机容量及共享设备绑定；问题可跳到对应对象。
- 模拟包络数据带有模拟依据，不会据此核定现场车体或最大载箱安全尺寸。

### 补齐已有后台的 Web 操作入口

- `/communication`：读取与保存既有 PLC、AGV 通信配置，保留后台修订校验和运行中修改限制。保存不等于自动启动设备，要求重启的设置仍按后台规则生效。
- `/resource-review`：查看资源原占用、提交核对与审批，保留后台权限、原任务和释放证据校验；默认不开启写操作。
- 现场恢复页增加上述入口与工程校验链接，继续复用原任务查询、取消和启动恢复接口。

## 隔离展示入口

预览：`http://127.0.0.1:5297/#/engineering`。

现场发布包在 `高级工具\Web工程配置模拟` 下提供 `启动Web工程配置模拟.cmd`、`停止Web工程配置模拟.cmd` 双击入口，调用下列仓库脚本。根目录只保留日常“启动最新版Web.cmd／停止最新版Web.cmd”，工程模拟入口不是日常入口的替代品。

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File tools/Start-WebEngineeringSimulation.ps1 -Build
```

构建完成后日常启动本模拟可省略 `-Build`。停止使用：

```powershell
powershell -ExecutionPolicy Bypass -File tools/Stop-WebEngineeringSimulation.ps1
```

模拟数据、日志和二进制独立存放于 `.artifacts/engineering-web-simulation`。启动脚本禁止占用 5199，不启动调度 Service；停止脚本核对可执行路径、PID 与启动时间，只停止本模拟进程。已有实例占用端口时先停止本模拟再启动，不接管其他进程。

模拟 WebHost 对设备、任务、导航、通信、资源处置、现场恢复和 WebSocket 接口统一拒绝访问；仅开放工程配置及配置标识接口。

### 展示测试操作

1. 打开工程配置中心，载入“300 工位 / 5 车”合成示例。
2. 编辑对象或导入 CSV，核对新增、修改和保留数量，保存草稿。
3. 运行统一校验，点击问题进入对应配置修正。
4. 输入发布说明，生成工程配置版本。
5. 选择版本进行模拟，查看任务、九阶段模型、路线、资源预约、并发数量和最终待机位置。
6. 将车辆设为离线或阻塞资源后重新模拟，检查不能分配的原因；可下载完整报告。

发布此工程版本仅用于配置快照和模拟，并不激活现场运行地图或下发机器人地图。

## 明确边界与后续工作

这是配置中心和离散资源预约模拟的第一批交付，不能作为五台实车并发或厂区安全验收结论。模拟使用配置距离、速度和固定 PLC 耗时，不模拟车体几何碰撞、制动、真实电气时序或运行中通信中断恢复；模拟总时长不是现场产能预测。道路只有显式绑定交通资源才参与互斥，彩色区域不自动产生交通规则。

既有真实业务运行器的两工位入口、单组倒料配置尚未迁移为新的车辆池与多倒料运行契约。新配置中的多工位、多车辆池、多倒料支持目前用于校验和模拟；真实 28 阶段握手点表、现场包络核定参数的完整 Web 编辑与版本切换仍需继续打通，不能认为已能向 300 个真实工位派车。

下一批应把经校验的工程版本接入持久化呼叫队列和现有九步执行器：保持任务、车辆、箱体及资源归属，增加车辆池选择、多倒料排队和独立待机分配；再做通信故障、取消恢复和死锁场景验证，随后按两车到五车逐步现场验收。日常 5199 部署时需另行备份并承接既有数据库与工程方案。
