# GitHub 源码范围与本地配置

仓库是私有开发工程，不是现场资料或运行环境的备份。

上传：解决方案、各模块源码、XAML、项目和依赖锁文件、界面图标/主题、自有架构说明、通用模板、测试及构建脚本。

本地保留但不提交：真实 appsettings（包括 Development）、PLC现场点表、CAD/现场地图/点云、厂家协议档案、第三方研究资料、联调/发布证据、发布包、数据库、日志、缓存、授权文件及密码密钥。忽略不等于删除，不影响原有程序使用这些本地文件。

首次克隆执行 `tools/Initialize-LocalConfiguration.ps1`，从 appsettings.example.json 创建安全配置。脚本不会覆盖已有文件；示例关闭设备通信、写入及调度，未配置现场点表。请按实际现场权限另外提供输入，不能把示例当生产配置。

CAD定向整理工具、现场点表生成器及依赖厂家档案的外部资料不随源码分发；通用编译不需要它们。协议文档完整性工具需要另外提供本地档案才能运行。地图交通烟测默认生成合成DWG，也可通过 AGV_TEST_DWG_PATH 显式指定自己的CAD夹具，不再硬编码开发者路径。

首次上传前，对实际Git候选文件做禁止路径、文件大小及凭据规则检查；另人工核对示例IP、图标、配置与外部资料边界。`Test-SourceUpload.ps1` 不打印命中的凭据内容，不代表对所有秘密的完备识别。

从暂存区导出的干净目录，使用示例配置完成依赖还原及 Debug 编译（0错误）；现有 ImageSharp 漏洞警告仍保留，未屏蔽。该验证不包含现场运行、真实设备协议验收或对第三方许可的法律结论。
