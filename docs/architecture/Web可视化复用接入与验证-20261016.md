# Web 可视化复用接入与验证

日期：2026-10-16。

## 本次结果

新增 `AgvDispatch.Web` 和 `AgvDispatch.WebHost`，在保留现有调度后台及 WPF 的基础上，提供可操作的浏览器试用页面。WebHost 已加入主解决方案。

复用来源为 `https://gitee.com/medicalprogrammer/agv-web-visible`，提交 `211179fc23395b93c34a8667ad7f4c7812ac28ba`。实际复制上游 `MeshUtils.ts`，页面直接使用站点、路径、等待位和文字标签绘制函数；保留原 MIT 许可及版权。仅调整其 IPoint 类型引用。来源见 `AgvDispatch.Web/src/vendor/agv-web-visible/UPSTREAM.md`。

这是绘制模块复用加项目适配，不是把整个开源前端原样部署。Vue 页面、场景生命周期和接入层为本次新增。没有使用上游 Node 调度后台、远程代理地址、浏览器寻路或动画结束后上报业务完成逻辑。

## 功能与链路

- 导航图三维/俯视、站点和路径、路段选择高亮、车辆选择、共享资源范围。
- 车辆状态、电量、原始XY、任务列表及筛选、任务步骤、PLC条件及设备字段。
- 明确标注的合成示例及九步播放/单步，不产生设备动作。
- HTTP查询、WebSocket快照、创建条件与路线核验。任务提交默认关闭；接口开启后仍委托主后台核验和执行。

链路为：浏览器 → 本机 ASP.NET Core WebHost → 现有 Named Pipe → 原 Service。WebHost 不直接调用设备接口。后台仍是业务状态和执行结果来源，客户端关闭不改变后台执行职责。

第一版固定监听 `127.0.0.1`，限制 API 同源访问。没有做远程多人认证。默认试用包连接独立占位管道 `AgvDispatch.WebPreview`，不自动连接现场主后台。

## 试用位置

根目录 `发布包/Web可视化试用`：自包含WebHost、前端静态文件、启动/停止脚本、说明、许可和文件哈希。

双击 `Start-WebPreview.cmd`，页面默认合成示例。需要读取已有后台时，先停止旧预览，再执行 `Start-WebPreview.ps1 -PipeName 实际管道名`。脚本不启动主服务、不启用设备写入，Web任务提交保持关闭。

开发和限制详见 `AgvDispatch.Web/README.md`。
