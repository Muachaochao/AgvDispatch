## 入口同步

使用 `tools/Set-LatestWebRelease.ps1 -BundleDirectory <发布包内目录>` 统一更新启动、停止、旧“界面修复版”别名、版本指向和根目录说明。旧入口及说明存入入口历史。不通过手工修改 JSON 单独切换版本。

验证器默认只接受初始清单中的文件；`-AllowRuntimeData` 只额外接受指定位置的启动器状态、SQLite、日志及工程方案 JSON，已列入清单的文件仍需哈希完全一致。未知程序、未知额外文件和目录链接均拒绝。它不证明配置已迁移或现场可运行。固定入口更新使用该参数，解决候选包使用后产生运行数据无法再设置入口的问题。
