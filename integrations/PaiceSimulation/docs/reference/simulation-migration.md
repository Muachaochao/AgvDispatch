# 5199 仿真功能迁移台账

排策智演的主工程工作区使用 5199 的隔离仿真接口、设备模型和调度引擎。旧页面与排策智演共用 5199 仿真的业务组件，通过各自的接口适配器运行。日常 5199 Web 仍使用原入口。历史方案、实例和报告沿用主工程的现有存储。

| 5199 能力 | 排策智演入口 | 对照验收 |
| --- | --- | --- |
| 运行总览、在线与载荷、下一步、启动与停止、二维与三维、全厂与车辆附近 | 运行总览 | 检查实例身份、车辆状态和下一步入口。二维、三维核对同一套坐标。 |
| 工程身份、现场参数只读拉取、CAD／RPJ 与导航图导入、PLC CSV、自动绑定、方案保存和清理、最近实例、物理模型参数 | 工程与地图 → 环境工具 | 绑定同一 B07 地图与点表。地图、工位、双线、初始点与 5199 实例相符。失效配置能定位。 |
| 工程点位检查、地图搜索、方案另存、启动预检查 | 工程与地图、场景与呼叫 | 选择保存方案、检查、启动，返回同一轮的运行监控。 |
| 单次／随机业务计划与完整业务、同批呼叫、自定义批次和持续积压 | 场景与呼叫、全部场景 | 检查计划次数、种子、批次、工位、间隔、轮次、超时和中止结果。 |
| 断连重连、PLC 延迟及卡位、后台重启和恢复、返程取消、丢回包、道路阻塞、障碍改道、安全站回退、取料／满箱／返空／道路中段／安全站／人工超时场景 | 全部场景 | 每个场景能独立选择，参数和预期结果明确。按场景验证是否应继续原任务、保留路权或转人工。 |

| 单车暂停／恢复、障碍、通信、充电、丢回包、取消、倍率、道路阻塞、PLC 延迟和设备故障 | 故障演练 | 选择目标并核对控制回执及设备反馈。 |
| 协议服务器、电梯／门、即时信号与信号时间轴 | 工程与地图 → 环境工具 | 在同一隔离实例启动、操作、复位及停止虚拟设备。 |

## 页面和接口

`/simulation?mode=main&section=overview` 是默认工作区。登录后使用 `/dashboard` 进入同一总览。`engineering`、`plan`、`monitor`、`diagnosis`、`faults`、`recovery`、`report` 是侧栏业务入口。`environment`、`scenarios`、`task-evidence`、`report-evidence` 打开对应的完整工具。同一入口支持可复制的地址与浏览器前进、后退。`mode=native`、`mode=compare`、原任务集和管理员地址兼容已有链接。

## 排策智演工作区界面

- 侧栏分组显示业务入口，图标与文字同时可见。窄屏可由顶部菜单按钮打开侧栏，选择入口、点击遮罩或按 Escape 后关闭。
- 运行总览使用车间地图的浅色只读预览，支持点位和道路搜索、编号开关、滚轮缩放、平移、缩略图拖动、比例尺和全屏。预览使用地图卡片的全部宽度，节点与道路的属性、统计和校验在车间地图页面查看。三维通过「3D 预览」打开。地图读取当前隔离实例绑定的工程地图，B07 全厂地图显示为「全厂五车仿真」，工位和车辆数量按当前实例显示。车辆反馈和任务路线叠加在地图上，反馈过期时仍可辨识。技术实例信息可展开查看，未取得地图时提供工程配置入口。
- 工程与地图优先选中已保存的 B07 五车全厂方案。加载配置后可打开同款地图预览，并在工程选点区继续核对初始位、停靠点和 PLC 绑定。加载配置及预览使用只读检查，不启动或切换当前隔离实例。
- 工程、呼叫、任务和报告页使用一致的标题、卡片和相关操作样式。调度诊断的六层调度与滚动匹配标记当前视图。嵌入的 5199 仿真工具使用排策智演的浅色工作区样式，地图保留自身的底色和图例。
- 业务路由、地图交互、权限、接口及数据格式沿用本台账中的约定。工作区主题作用于排策智演。

打开运行总览和工程与地图，核对当前实例与加载方案的实际地图名称、点位、道路和工位数量。总览搜索 `CNC-291`，拖动缩略图，全屏查看，并在同一地图的三维预览定位工位。刷新车辆反馈时缩放和平移位置保留。打开任务与车队和调度诊断，核对车辆状态和九步入口。缩窄窗口后核对菜单的打开与退出。

排策智演代理的固定只读接口包含仿真快照、点表、恢复候选、报告和证据 ZIP。现场地图及通信点表只读，用于复制配置。设备控制、方案、恢复和生命周期操作经 `/api/dispatch/main/simulation` 转发至主工程隔离接口。超时恢复使用原任务编号。证据包需提供报告编号。隔离诊断使用 `/api/dispatch/main/simulation/dispatch-pipeline` 和 `/api/dispatch/main/simulation/dispatch-optimization`，对应 WebHost 仿真桥同名读取能力；旧发布包缺少这些接口时显示该能力不可用。

| 操作 | 隔离接口，在 `/api/dispatch/main/simulation` 下 |
| --- | --- |
| 查看运行实例、地图与状态，启动或停止环境 | `GET /api/dispatch/main/simulation`、`GET /live`、`POST /start`、`POST /stop` |
| 准备新实例、导入地图及点表、预检与管理方案 | `POST /new-instance`、`POST /configure`、`GET /point-table`、`POST /point-table-validate`、`POST /scheme-select`、`POST /scheme-save`、`POST /scheme-start`、`POST /scheme-delete` |
| 开始和停止场景 | `POST /run`、`POST /abort` |
| 看原任务、九步、命令、路线和路权 | `GET /tasks`、`GET /tasks/{id}`、`GET /snapshot`、`GET /resources`、`GET /monitor` |
| 查看六层观察和滚动匹配，保存当前隔离策略 | `GET /dispatch-pipeline`、`GET /dispatch-optimization`、`POST /dispatch-optimization/options` |
| 控制虚拟车、PLC 和道路故障 | `POST /control` |
| 操作协议服务器、设备模型与定时信号 | `POST /protocol-start`、`POST /protocol-stop`、`POST /equipment-start`、`POST /equipment-control`、`POST /equipment-stop` |
| 核对人工恢复条件，提交处置和放行 | `POST /recover`、`POST /recover-release`、`GET /timeout-recovery/{id}`、`POST /timeout-recovery/{id}/execute` |
| 选择和比较报告，播放回放，导出 JSON、WebM、ZIP | `GET /report?id=…`、`GET /replay?id=…`、`GET /archive?id=…`。浏览器用回放采样生成 WebM。 |

## 场景验收

| 全部场景中的选项 | 验收观察 |
| --- | --- |

| 多工位同时呼叫 | 同批呼叫独立建单，路权等待有记录，车辆通过后释放。 |
| 正式调度持续排队测试 | 按计划呼叫，忙车排除，待派任务能在车辆和路权可用后接单。 |

| 车辆断连与重连 | 记录断连、恢复及原任务的后续动作。 |
| PLC 反馈延迟 | 对应步骤等待，收到反馈后再进入下一步。 |
| PLC 卡位与恢复 | 卡位期间保留业务状态，信号复原后按原步骤推进。 |
| 后台重启与恢复屏障 | 重启后核对原车、原任务、载荷和占用，再按屏障条件放行。 |
| 恢复后继续原任务 | 人工复核通过后，按原任务编号续接。 |
| 车端返程中途取消 | 记录车端取消，核对返箱状态、占用及人工核对入口。 |
| 运输命令回包丢失 | 按原命令和原任务核对结果及重试次数。 |
| 道路临时阻塞后恢复 | 阻塞和解除均可定位，核对续行和资源释放时点。 |
| 前方障碍自动改道 | 对照原导航终态、新路线和原车归属。 |
| 道路中段自动退回安全站 | 记录原命令取消、后退许可、实际到站和续行。 |
| 取料途中受阻并超时 | 保留原任务、空载状态和超时证据。 |
| 满箱运输受阻并超时 | 保留满箱责任、原车、目标倒料点及路权。 |
| 空箱返程受阻并超时 | 核对返箱、放箱和 PLC 收尾状态。 |
| 道路中段受阻并超时 | 继续申请前核对可信车位及安全站条件。 |
| 安全点转移后继续 | 受控到达安全点后核对原车、原任务和续行。 |
| 无法恢复转人工处置 | 核对人工处置项、保存的占用和操作回执。 |

1. 登录后从运行总览进入工程与地图，选择 B07 方案，检查实际点位、初始位置和 PLC 绑定。
2. 从场景与呼叫配置一次满箱呼叫，检查并启动。在任务与车队打开九步及路线，再进入任务证据核对路权和合并时间轴。
3. 从故障演练打开任一车辆控制，从人工处置打开恢复对象，从历史证据选择已保存报告，核对视频、JSON 和 ZIP。
4. 对隔离发布候选验收五车固定种子 20 单，逐单核对建单、派车、九步完成、资源释放与出区。保留失败、中止及证据不足结果。需要真实执行的故障场景逐项记录结果。
