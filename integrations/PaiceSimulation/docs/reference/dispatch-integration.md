# 主工程数据接入契约

独立应用完整采用排策智演的 Vue 3、Element Plus、Three.js、ECharts 页面及 Java 算法后台。访问入口为 http://127.0.0.1:5270，Java API 为回环 5271。主工程数据代理固定使用 http://127.0.0.1:5199，路径前缀为 `/dispatch-api`。原生 API 继续使用 `/api`，原生实时通道继续使用 `/ws`。

## 统一仿真前台

排策智演是用户可见的唯一仿真前台。“仿真中心”在一个入口中提供原生算法、主工程调度和对比实验三个工作区。5199 的仿真测试中心不再出现在日常导航中，其隔离运行能力继续作为主工程调度实验的运行底座。

主工程调度实验的权威决策方是 5199 内的 `AgvDispatch.Service`。排策智演负责选择任务集、创建干净实例、提交呼叫计划、观察车辆和任务、汇总报告与保存实验记录。排策智演不在该模式中向虚拟车辆发送路线。

同一时刻只允许一个主工程调度实验。新建实验会先停止当前主工程场景并创建新的隔离实例，旧实验记录和上一实例证据保持不变。

## 主工程调度实验 API

排策智演后台提供以下受 JWT 保护的固定接口。

```text
POST /api/dispatch/experiments
GET  /api/dispatch/experiments
GET  /api/dispatch/experiments/{id}
POST /api/dispatch/experiments/{id}/stop
```

主工程原始观察和高级操作通过排策智演后台固定代理访问。

```text
GET  /api/dispatch/main/simulation
GET  /api/dispatch/main/simulation/live
GET  /api/dispatch/main/simulation/tasks
GET  /api/dispatch/main/simulation/tasks/{id}
GET  /api/dispatch/main/simulation/resources
GET  /api/dispatch/main/simulation/report
GET  /api/dispatch/main/snapshot
GET  /api/dispatch/main/maps
GET  /api/dispatch/main/maps/{id}/workspace
POST /api/dispatch/main/simulation/{action}
```

`{action}` 只接受 `start`、`stop`、`scheme-start`、`run`、`abort`。前端不再通过 Vite 直连 5199，也不再携带第二套跨域配置。代理只拼接固定的 5199 回环路径。

## 本地连接恢复

5199 控制桥与隔离 WebHost 之间使用短生命周期、容量受限的回环 HTTP keep-alive 连接。Windows 下 `ConnectionAbortedError` 或 `WinError 10053` 表示旧空闲连接已被服务端关闭，不能直接解释为调度或 PLC 失败。

读取请求遇到 `RemoteDisconnected`、`BrokenPipeError`、`ConnectionResetError` 或 `ConnectionAbortedError` 时，关闭旧连接并新建连接重试一次。写请求保留原请求编号和幂等边界，连接中断后不得自动重放，由调用方按原请求结果核对。

创建请求字段：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `name` | string | 是 |  | 1 至 128 个字符的实验名称 |
| `schemeId` | string | 是 |  | 5199 已保存方案 ID |
| `roadnetId` | number | 是 |  | 排策智演路网 ID |
| `taskSetId` | number | 是 |  | 与路网绑定的任务集 ID |
| `scenarioName` | string | 否 | `dispatch-backlog` | 当前只接受 `dispatch-backlog` |
| `timeoutSeconds` | number | 否 | `7200` | 30 至 604800 秒 |

当前任务映射规则：

- 任务 `from` 必须是 `BUS-CNC-001` 至 `BUS-CNC-305`，或直接使用 `CNC-001` 至 `CNC-305`。
- 所有任务 `to` 必须相同，且必须是 `DUMPER-001`。5199 当前方案按该工位配置倒料目标。
- 每个任务转换成一个 `CNC-xxx` PLC 呼叫，`atSeconds` 固定为 0。
- 呼叫不指定车辆。车辆由主工程正式调度选择。
- 当前任务集包含 `BUS-CNC-001` 至 `BUS-CNC-020` 时，转换结果为 `CNC-001` 至 `CNC-020` 共 20 条呼叫。

接口返回的实验状态：

| 状态 | 含义 |
|---|---|
| `PREPARING` | 正在停止旧场景、创建实例或启动主工程服务 |
| `SUBMITTED` | 呼叫计划已提交，等待主工程场景开始 |
| `RUNNING` | 场景运行中 |
| `FINISHED` | 主工程场景判定通过 |
| `FAILED` | 创建或运行失败 |
| `ABORTED` | 用户停止或主工程场景中止 |

创建接口在后台任务受理后立即返回 `PREPARING`。前端每 2 秒读取一次实验详情。详情接口会读取 5199 当前轻量状态，更新实验状态和主工程场景摘要。

错误边界：

| 场景 | 业务码 | HTTP |
|---|---:|---:|
| 主工程接入功能未启用 | `5031` | 503 |
| 5199 不可达或返回无效 JSON | `5031` | 503 |
| 方案、任务集或路网不匹配 | `4000` | 400 |
| 当前任务无法映射为已配置 CNC 呼叫 | `4000` | 400 |
| 查看或停止其他用户实验 | `4030` | 403 |
| 实验不存在 | `4040` | 404 |

配置项：

| 配置 | 默认值 | 说明 |
|---|---|---|
| `agv.main-dispatch.enabled` | `true` | 是否允许创建主工程调度实验 |
| `agv.main-dispatch.base-url` | `http://127.0.0.1:5199` | 5199 回环地址 |
| `agv.main-dispatch.start-timeout-seconds` | `240` | 等待隔离实例进入运行态的上限 |

环境变量 `AGV_MAIN_DISPATCH_ENABLED`、`AGV_MAIN_DISPATCH_BASE_URL` 和 `AGV_MAIN_DISPATCH_START_TIMEOUT_SECONDS` 可覆盖配置。

## 页面与数据

“概览、车间地图、任务集、仿真中心、用户管理、数字字典”采用统一入口。“仿真中心”有三个页签：原生算法、主工程调度、对比实验。主工程调度页增加当前隔离仿真实例的三维观察、车辆、原任务详情、交通资源、方案启动、实验启动、场景运行、终止编排及报告查询。轮询间隔为 1 秒，串行请求，离页取消。读取失败保留最后观察并显示断连，禁用写操作。图形坐标使用 X/Y 米制映射至 X/Z，主工程角度乘以 180/π 转为原组件使用的角度值。状态未知或失联单独显示。

高频轮询使用 `/api/simulation/live` 轻量设备状态。实例首次出现或发生变化时再读取一次完整 `/api/simulation`，保留地图、方案、配置和报告元数据。读取 Web 地图及方案控制仍使用完整接口。该路径避免 B07 的 305 工位配置和大点表在每个 1 秒轮询中重复传输。

“读取 Web 仿真地图”读取 `/api/simulation` 中当前仿真实例实际绑定的米制地图。页面展示实例名称、地图名称、节点数、道路数和来源摘要。当前日常 Web 仿真方案为 `B07-1F·305工位·5车·200单·双行线·安全停点v3·0.75m/s`，绑定 `B07-1F·305CNC·现场双线终端修订`，包含 1112 个节点、1887 条有向道路、305 个 PLC 工位和 5 台虚拟车。上传文件仅作为备用入口。

读取成功后直接生成转换预览，默认路网名称为简短的“全厂五车仿真”。其他地图使用 `<地图名称>（仿真）`。默认初始停放点优先使用当前车辆站点对应的地图节点，其次使用原图充电点或第一个工位，页面允许修改。米制完整定义经转换预览后另存为 Java 后台的独立路网。

地图身份直接采用主工程 `SIM_MAP_IDENTITY` 给出的实例名、来源名和 `definitionHash`，不在前端另算替代摘要。编辑页同时显示“最新 Web 来源 1112 节点 / 1887 道路 / 305 工位”和实验图“1108 节点 / 1344 路段”，后者仅排除了地图四角的 4 个单向不可往返端点及 8 条关联边。两套数量并列展示，避免把算法裁剪图误解成旧地图。

节点超过30个时，只读预览沿用原模板的浅色网格、左下角图例和右上角概览面板。常驻文字与圆角轮廓按功能区区分，“等待区”使用绿色，“倒料区”使用青色，“充电区”使用紫色，三个轮廓互不相交。港口、排屑机、甩干机和铝屑箱等CAD参考点不绘制常驻红框和文字，也不再显示“铝屑终端处理与倒料区”总标题。充电区轮廓完整包住两个充电位，倒料区轮廓包含倒料设备。搜索、悬停、选中和属性面板仍可定位具体对象。进入“编辑”后恢复完整业务工位与充电点标签，方便维护。

三维预览在节点超过200个时建立道路层级。主通道使用深蓝色连续线，连接工位、候车位和充电位的支路分别强调为青色和琥珀色；普通路径点不再绘制灰色节点，工位保持蓝色停靠点。当前B07源图的工位连接边多数只有0.05–0.50米，因此二维只读预览和三维场景沿原支路方向把过短支路最短显示为1.2米，让工位明确位于主通道两侧。该变化只影响显示，不修改算法坐标、道路长度、任务端点或源地图。大规模方向箭头和普通节点标签继续隐藏，仅显示充电区名称。二维编辑、搜索、属性面板和实时车辆状态继续提供完整定位信息。

三维预览的网格、镜头远裁面和雾化范围按节点及道路采样点共同计算。网格以路网中心为原点，尺寸取路网最大跨度的1.45倍，保证全部道路和端点落在网格内并保留四周余量。容器由对话框初始尺寸变为实际尺寸时会重新执行镜头适配。

“简化道路”默认开启。弯道和贝塞尔道路仅保存在来源记录中，实验路网使用起终点直线显示，原道路长度、速度和方向继续用于算法。关闭该选项时，曲线按 24 段折线导入，用于核对原始几何。当前 B07 源图有 1887 条有向道路，成对正反向道路合并后生成 1112 个节点、1352 条实验道路。导入时排除4个不可往返死端节点和8条关联道路，最终保存为1108个节点、1344条道路，校验错误为0。

导入预览显示完整源图。校验错误标红，实验副本排除项标橙。点列表可在图中放大定位，查看节点原始米制坐标、关联道路编号和单向或双向设置；关联道路在图中同时高亮。可在预览里修改关联道路的单向或双向设置，再重新预览并校验。修改只作用于待保存的实验副本，并随来源记录保存；重新读取来源会清空本次修改。

工程配置、导入校验、任务选点、车间地图和仿真运行的二维或三维地图提供编号查找、缩放、平移、适应窗口和全屏。地图右上角可展开或收起缩略图，点击缩略图移动视图。查找优先匹配完整编号，也可按片段循环定位。可查看地图点位、路段及运行地图中已显示的车辆。查找和高亮操作不提交任务端点或修改道路绑定。

原生算法保存校验采用 `RoadNetValidator`。节点和道路编号须唯一；道路端点须存在且不同；同一端点对须符合副本的建边规则；坐标须有效，长度、速度和容量须为正；路网至少含一个充电位，任一充电位须可达全部工位；节点不得只进不出；缓存位位于只连接一条道路的支路末端。「初始点可往返」只在启用对应导入范围时执行。

节点 ID 保留，`agvSiteId` 用于车辆站点到地图节点的别名匹配。原模板编辑器的编辑边界从 0 开始，实验副本统一平移到正坐标画布，并将 Y 轴取反以保持 Web 仿真的上下方向。来源记录保存 `coordinateOffset` 和显式 `coordinateTransform`，原始坐标为实验 X 加 X 偏移、Y 偏移减实验 Y。实时三维观察也先执行同一 Y 轴映射，再叠加主工程车辆反馈。画布尺寸根据副本范围生成，并保留四米边距。

禁用节点与道路跳过。未知节点类型映射为 JUNCTION，Station 映射为 WORKSTATION，Charging 映射为 CHARGER，Waiting 映射为 BUFFER，ChargingPoint 映射为 CHARGER。主工程 WaitingPoint 可位于通行路段中，导入为 JUNCTION 并记录转换提示，候车业务语义保存在来源定义。原模板 BUFFER 要求叶节点，不能直接承接通行候车点。速度与长度必须大于零。原算法校验要求充电位和强连通路网，所选实验初始停放点在实验副本中标为 CHARGER，页面展示这一转换。强连通性及重复建边由原校验器检查。算法实验道路容量显式设为 1。

直线保持端点。关闭“简化道路”时，贝塞尔与圆弧按 24 段生成独立实验节点及边，保持总距离和速度。端点相反的成对道路在长度、速度一致时合并为一条双向道路，两个源道路 ID 均映射到该实验道路。同向或属性不一致的平行道路通过独立中间节点保留，避免原模板禁止重复端点对的约束。导入默认保留初始点的有向可往返区域。预览列出排除点；如果范围涉及工位、充电位、等待位等非普通路点，或 Web 当前工程绑定的车辆初始点与业务节点，阻止生成这一副本并列出点位。可取消该选项查看全图校验，也可从校验提示一键恢复可往返范围。裁剪作用于原生算法实验副本，原始全图及排除节点和道路保存在来源记录。转换结果记录原边到实验分段的映射。区域资源、厂家通行属性、PLC 条件、车体包络进入转换提示。来源、版本、摘要、原定义、转换提示及 ID 映射可下载为 JSON。三维观察使用原始地图的曲线采样，实时车辆保持反馈坐标。

原任务详情来自 `/api/simulation/tasks/{id}`。只提取已存在运输命令的路线端点，按当前导入图节点核对后预览为算法任务集。任务集保存采用 `/api/taskset`，保留原任务/命令 ID 的下载映射。九步任务详情在主工程接入页面按原数据展示。算法时钟 tick=100 ms，实验 makespan、waitTick 依旧显示原单位。PLC 循环耗时保留秒制。

## 主工程操作

GET `/api/simulation`、`/tasks`、`/tasks/{id}`、`/snapshot`、`/resources`、`/report` 读取隔离环境。POST `/api/simulation/start`、`/stop` 管理隔离后台，`/scheme-start` 提交已保存方案 ID，`/run` 提交页面选中的场景及轮次，`/abort` 中止场景后续编排。所有写操作使用页面显式按钮，操作期间禁用重复提交，操作失败展示后台原因。面板显示仿真实例名称与最后成功观察时间。

代理仅接受上述固定路由以及主工程读取所需的 `/api/simulation`。原生 Java API 的 JWT 只发往 `/api`，主工程代理通过独立 fetch 调用。既有工程数据库、现场车辆通信配置与 5199 日常入口由主工程管理。

## 运行监控与报告回放

运行监控默认打开一条有车辆的执行中任务。多单呼叫的「查看九步」和车辆的「路线与九步」切换到同一份任务详情。九步列表位于原任务清单之前，显示当前步骤、起止点、耗时、等待说明、完成条件以及下方的 PLC 与机构反馈。车辆入口优先查找进行中的业务任务。

运行地图上方显示所选车辆、对应导航命令的路线起止点及命令状态。有车端任务编号时匹配该导航命令，也可手动查看所选任务已记录的其他导航命令。缺少当前导航命令时显示提示。历史路线标为历史命令，路线使用命令附带的步骤路线快照及同一地图的道路几何。滚动窗口的快照可以覆盖整个运输步骤。

报告页可选择已保存的历史报告，载入对应地图与观察时间轴，按帧播放、暂停或拖动时间轴查看车辆和任务。支持 WebM 编码的浏览器可从时间轴导出视频。地图缺失时保留车辆位置和任务采样，显示来源提示。无采样的报告显示「本轮没有可回放的观察采样」。

`GET /api/dispatch/main/simulation/replay?id=<报告编号>` 只读转发至主工程的 `/api/simulation/replay`，`id` 必填且为 32 位十六进制编号。返回 `id`、`timeline`、该轮 `map` 及可选 `mapMessage`、`sampled`。报告不存在、源文件不可读或采样超出范围时展示主工程错误。原有报告格式和导航命令保持兼容。

从正在执行的呼叫打开九步，核对当前步骤、车端导航编号和地图上的路线。切换车辆和历史导航命令后检查高亮与起止点。打开一份已完成报告，核对原图、车辆位置、任务状态、时间轴和下载的 WebM；再切换报告，确认回放随报告编号更新。

### 等待状态与路权明细

运行监控的多单呼叫区分「待触发」「已触发 · 待建单」「已建单待派」「已派车等路权」「等 PLC／机构反馈」与执行、故障、结束状态。车辆卡片沿用已绑定任务的等待状态。待派任务的候选路线受阻时，明细标为「候选路线」，保留任务待派状态。已绑定车辆按原任务与车辆编号匹配当前路权申请。九步的 PLC 或机构步骤独立显示反馈等待。

路权明细显示申请起止点、连续等待时长、阻塞资源和各资源的持有车辆。连续等待时长使用主工程快照的计时，起点未知时显示「等待起点未知」。快照无占用者时展示调度给出的原因，包括等待重新申请。快照断开或过期时，实时明细和计时暂停。相同资源的多个持有车辆合并到一行。

`GET /api/dispatch/main/simulation/monitor` 使用固定只读路径 `/api/simulation/snapshot`，无需参数。返回 `connected`、`resources` 与可空的 `traffic`。`traffic` 包含快照时间、是否截断及原快照的 `Waiting` 请求；事件历史留在主工程快照。原仿真接口保持兼容。

## 来源记录持久化

导入路网的 `integration` 字段随 roadnet_json 存入独立 H2，包含来源身份、原始定义、坐标偏移、道路映射、排除清单和导入图指纹。字段可为空，旧路网和旧构造方法继续支持。地图编辑页保存时保留来源记录，任务导入以当前图指纹核对编辑结果。浏览器缓存仅兼容早期副本，服务端来源记录优先。
