# 主工程数据接入契约

独立应用完整采用排策智演的 Vue 3、Element Plus、Three.js、ECharts 页面及 Java 算法后台。访问入口为 http://127.0.0.1:5270，Java API 为回环 5271。主工程数据代理固定使用 http://127.0.0.1:5199，路径前缀为 `/dispatch-api`。原生 API 继续使用 `/api`，原生实时通道继续使用 `/ws`。

## 页面与数据

“概览、车间地图、任务集、仿真运行、对比实验、用户管理、数字字典”采用原项目页面。“主工程接入”增加当前隔离仿真实例的三维观察、车辆、原任务详情、交通资源、方案启动、场景运行、终止编排及报告查询。轮询间隔为 1 秒，串行请求，离页取消。读取失败保留最后观察并显示断连，禁用写操作。图形坐标使用 X/Y 米制映射至 X/Z，主工程角度乘以 180/π 转为原组件使用的角度值。状态未知或失联单独显示。

高频轮询使用 `/api/simulation/live` 轻量设备状态。实例首次出现或发生变化时再读取一次完整 `/api/simulation`，保留地图、方案、配置和报告元数据。读取 Web 地图及方案控制仍使用完整接口。该路径避免 B07 的 305 工位配置和大点表在每个 1 秒轮询中重复传输。

“读取 Web 仿真地图”读取 `/api/simulation` 中当前仿真实例实际绑定的米制地图。页面展示实例名称、地图名称、节点数、道路数和来源摘要。当前日常 Web 仿真方案为 `B07-1F·305工位·5车·200单·双行线·安全停点v3·0.75m/s`，绑定 `B07-1F·305CNC·现场双线终端修订`，包含 1112 个节点、1887 条有向道路、305 个 PLC 工位和 5 台虚拟车。上传文件仅作为备用入口。

读取成功后直接生成转换预览，默认路网名称为简短的“全厂五车仿真”。其他地图使用 `<地图名称>（仿真）`。默认初始停放点优先使用当前车辆站点对应的地图节点，其次使用原图充电点或第一个工位，页面允许修改。米制完整定义经转换预览后另存为 Java 后台的独立路网。

节点超过 30 个时，只读预览使用与 Web 仿真一致的深色全厂图样式，显示青色道路轮廓、工位环点及区域轮廓。常驻文字只保留“铝屑终端处理与倒料区”和“双充电位”。港口、排屑机、甩干机和铝屑箱等 CAD 参考点不绘制常驻红框和文字。终端区隐藏与上方产线重叠的红色边框，充电区边界两侧各扩展 0.35 米以完整包住两个充电位。搜索、悬停、选中和属性面板仍可定位具体对象。进入“编辑”后恢复完整业务工位与充电点标签，方便维护。

三维预览在节点超过 200 个时缩小节点模型，隐藏大规模方向箭头和普通节点标签，仅显示充电位名称。二维编辑、搜索、属性面板和实时车辆状态继续提供完整定位信息。

“简化道路”默认开启。弯道和贝塞尔道路仅保存在来源记录中，实验路网使用起终点直线显示，原道路长度、速度和方向继续用于算法。关闭该选项时，曲线按 24 段折线导入，用于核对原始几何。当前 B07 源图有 1887 条有向道路，成对正反向道路合并后生成 1112 个节点、1352 条实验道路。导入时排除4个不可往返死端节点和8条关联道路，最终保存为1108个节点、1344条道路，校验错误为0。

节点 ID 保留，`agvSiteId` 用于车辆站点到地图节点的别名匹配。原模板编辑器的编辑边界从 0 开始，实验副本统一平移到正坐标画布，并将 Y 轴取反以保持 Web 仿真的上下方向。来源记录保存 `coordinateOffset` 和显式 `coordinateTransform`，原始坐标为实验 X 加 X 偏移、Y 偏移减实验 Y。实时三维观察也先执行同一 Y 轴映射，再叠加主工程车辆反馈。画布尺寸根据副本范围生成，并保留四米边距。

禁用节点与道路跳过。未知节点类型映射为 JUNCTION，Station 映射为 WORKSTATION，Charging 映射为 CHARGER，Waiting 映射为 BUFFER，ChargingPoint 映射为 CHARGER。主工程 WaitingPoint 可位于通行路段中，导入为 JUNCTION 并记录转换提示，候车业务语义保存在来源定义。原模板 BUFFER 要求叶节点，不能直接承接通行候车点。速度与长度必须大于零。原算法校验要求充电位和强连通路网，所选实验初始停放点在实验副本中标为 CHARGER，页面展示这一转换。强连通性及重复建边由原校验器检查。算法实验道路容量显式设为 1。

直线保持端点。关闭“简化道路”时，贝塞尔与圆弧按 24 段生成独立实验节点及边，保持总距离和速度。端点相反的成对道路在长度、速度一致时合并为一条双向道路，两个源道路 ID 均映射到该实验道路。同向或属性不一致的平行道路通过独立中间节点保留，避免原模板禁止重复端点对的约束。用户可显式选择“仅导入初始点可往返区域”，按有向可达交集保留可往返分量，原始全图及排除节点和道路保存在来源记录。默认导入全部启用节点，由原校验器报告死端问题。转换结果记录原边到实验分段的映射。区域资源、厂家通行属性、PLC 条件、车体包络进入转换提示。来源、版本、摘要、原定义、转换提示及 ID 映射可下载为 JSON。三维观察使用原始地图的曲线采样，实时车辆保持反馈坐标。

原任务详情来自 `/api/simulation/tasks/{id}`。只提取已存在运输命令的路线端点，按当前导入图节点核对后预览为算法任务集。任务集保存采用 `/api/taskset`，保留原任务/命令 ID 的下载映射。九步任务详情在主工程接入页面按原数据展示。算法时钟 tick=100 ms，实验 makespan、waitTick 依旧显示原单位。PLC 循环耗时保留秒制。

## 主工程操作

GET `/api/simulation`、`/tasks`、`/tasks/{id}`、`/snapshot`、`/resources`、`/report` 读取隔离环境。POST `/api/simulation/start`、`/stop` 管理隔离后台，`/scheme-start` 提交已保存方案 ID，`/run` 提交页面选中的场景及轮次，`/abort` 中止场景后续编排。所有写操作使用页面显式按钮，操作期间禁用重复提交，操作失败展示后台原因。面板显示仿真实例名称与最后成功观察时间。

代理仅接受上述固定路由以及主工程读取所需的 `/api/simulation`。原生 Java API 的 JWT 只发往 `/api`，主工程代理通过独立 fetch 调用。既有工程数据库、现场车辆通信配置与 5199 日常入口由主工程管理。

## 集成版运行依赖

保留原模板页面和功能契约，前端构建工具使用 Vite 7.3.8、Vue 插件 6、vue-tsc 3.3.14，图表使用 ECharts 6.1.0。版本由 package-lock.json 锁定。安装完成后执行类型检查、构建、原模板浏览器检查和新增接口回归，核对兼容性。

## 来源记录持久化

导入路网的 `integration` 字段随 roadnet_json 存入独立 H2，包含来源身份、原始定义、坐标偏移、道路映射、排除清单和导入图指纹。字段可为空，旧路网和旧构造方法继续支持。地图编辑页保存时保留来源记录，任务导入以当前图指纹核对编辑结果。浏览器缓存仅兼容早期副本，服务端来源记录优先。
