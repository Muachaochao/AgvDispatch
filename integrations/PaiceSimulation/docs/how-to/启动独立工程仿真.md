# 启动独立工程仿真

日常运维也可以通过「AGV 软件助手」统一查看和启停本应用，步骤见 [从软件助手管理排策智演](从软件助手管理排策智演.md)。本文保留直接命令行启动方式，便于开发排障。

## 启动

<!-- runnable -->

在主工程根目录执行：

```powershell
pwsh -File tools/Start-PaiceSimulation.ps1
```

浏览器访问 http://127.0.0.1:5270，原生 Java 后台监听回环 5271。首次登录使用原模板账户 `admin / admin123` 或 `dispatcher / dispatcher123`。也可双击集成目录的“启动独立仿真.cmd”。首次运行会安装前端锁定依赖，构建 Java 模块及可执行包。Java 17 和 Maven 可通过 `-JavaHome`、`-MavenPath` 指定，本机已安装路径会被识别。`-Rebuild` 强制重新构建。

数据库、进程清单和日志存储于 `integrations/PaiceSimulation/.runtime`。原模板所有页面通过原生后台运行。日常使用前先启动主工程 5199。“仿真中心”是唯一仿真前台，包含原生算法、主工程调度和对比实验三个页签。主工程未运行时主工程调度页显示连接失败，原生地图、任务集、算法仿真和对比实验仍可使用。

## 导入 Web 仿真地图

1. 打开“仿真中心 → 主工程调度”。
2. 点击“读取 Web 仿真地图”。
3. 页面读取 5199 当前仿真实例实际绑定的 B07 五车地图，自动预选可用停放点并生成转换校验。
4. 核对地图名称、版本、节点、道路和提示。
5. 点击“保存仿真路网”。当前场景默认保存为“全厂五车仿真”。

“简化道路”默认开启，页面会按模板样式显示直线，算法仍使用 Web 地图中的原始道路长度。需要核对弯道形状时可关闭“简化道路”后重新预览。

保存后可进入车间地图继续编辑。选择具有相同来源摘要的目标实验路网，在原任务表勾选原任务，预览命令转换并保存实验任务集。

## 运行算法仿真

独立算法仿真使用 Java 后台。在“仿真中心 → 原生算法”选择路网、任务集、调度算法、车辆数和随机种子。运行中可暂停、继续、调速和重置。“对比实验”页签使用相同输入依次运行就近分配与贪心 ETA，并生成指标图表及历史记录。主工程调度实验的操作见 [运行主工程调度实验](运行主工程调度实验.md)。

临时验证工位之间的运输时，可以在“原生算法”中切换任务来源为“地图点选”，按 [在地图上创建仿真任务](在地图上创建仿真任务.md) 操作。

## 停止

```powershell
pwsh -File tools/Stop-PaiceSimulation.ps1
```

启动脚本对端口占用报错，停止脚本核对进程启动时间与可执行路径。进程身份变化时保留记录并报错。构建失败会停止启动并显示失败阶段。该入口单独管理回环 5270/5271 两个进程。
