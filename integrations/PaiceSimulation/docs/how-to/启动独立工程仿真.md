# 启动独立工程仿真

<!-- runnable -->

在主工程根目录执行以下命令，启动完整排策智演模板应用。

```powershell
pwsh -File tools/Start-PaiceSimulation.ps1
```

浏览器访问 http://127.0.0.1:5270，原生 Java 后台监听回环 5271。首次登录使用原模板账户 admin / admin123 或 dispatcher / dispatcher123。首次运行启动脚本安装前端锁定依赖，构建 Java 模块及可执行包。也可通过集成目录的“启动独立仿真.cmd”进入。Java 17 和 Maven 可通过 -JavaHome、-MavenPath 指定，本机已安装路径会被识别。-Rebuild 强制重新构建。

数据库、进程清单、日志存储于 integrations/PaiceSimulation/.runtime。原模板所有页面通过原生后台运行。进入“主工程接入”读取 5199 的隔离仿真接口，主工程未运行时页面显示连接失败，原生地图、任务集、算法仿真和对比实验仍可使用。

导入工程数据依次点击“读取隔离仿真地图”或“读取主工程活动地图”，选择实验初始停放点，预览转换与校验，确认保存实验副本。保存后可进入车间地图继续编辑。选择具有相同来源摘要的目标实验路网，在原任务表勾选原任务，预览命令转换并保存实验任务集。随后在“仿真运行”或“对比实验”选择相应路网及任务集。

停止独立应用执行以下命令。

```powershell
pwsh -File tools/Stop-PaiceSimulation.ps1
```

启动脚本对端口占用报错，停止脚本核对进程启动时间与可执行路径。进程身份变化时保留记录并报错。构建失败会停止启动并显示失败阶段。该入口单独管理回环 5270/5271 两个进程。
