# 运行主工程调度实验

本文说明如何在排策智演中把实验任务集交给 5199 的主工程调度程序执行。

## 适用场景

需要使用正式任务分配、A*、道路权、虚拟 Robokit、虚拟 PLC 和九步搬运逻辑验证算法效果时，使用主工程调度实验。只做快速算法对比时，使用“原生算法”页签。

## 前置条件

- 5199 日常入口已启动。
- 5199 中存在要使用的主工程仿真方案。
- 排策智演已导入与方案对应的 Web 仿真地图。
- 任务集已绑定该路网，任务起点使用 `BUS-CNC-xxx` 或 `CNC-xxx`，终点统一为 `DUMPER-001`。
- 当前主工程仿真可以停止，因为新实验会创建新的隔离实例。

## 操作步骤

1. 打开 http://127.0.0.1:5270 并登录。
2. 进入“仿真中心”。
3. 选择“主工程调度”页签。
4. 选择主工程方案。
5. 选择与当前地图绑定的任务集。
6. 输入实验名称和超时时间。
7. 点击“按任务集启动主工程实验”。
8. 在实验记录中观察状态从 `PREPARING` 依次变化为 `SUBMITTED`、`RUNNING`。
9. 在三维场景、车辆面板、任务表和交通资源面板观察主工程运行。
10. 任务结束后查看完成数、失败原因、报告编号和场景编号。

使用“五车20工位算法任务”时，页面应显示 20 条待提交呼叫，主工程场景显示 `dispatch-backlog`，五台虚拟车由主工程自动选择。

## 状态说明

| 状态 | 页面表现 |
|---|---|
| `PREPARING` | 正在停止旧场景并启动隔离实例 |
| `SUBMITTED` | 呼叫计划已提交 |
| `RUNNING` | 场景运行中 |
| `FINISHED` | 场景通过 |
| `FAILED` | 场景失败，详情中显示原因 |
| `ABORTED` | 已停止 |

## 停止实验

点击实验记录的“停止实验”。排策智演先中止后续编排，再停止隔离环境。历史记录保留，运行车辆由主工程停止。

## 常见问题

**启动按钮不可用**

检查 5199 是否运行、主工程方案是否加载、任务集是否与地图绑定。

**任务无法转换**

检查任务起点是否为 `BUS-CNC-001` 至 `BUS-CNC-305` 或 `CNC-001` 至 `CNC-305`。检查所有任务终点是否为 `DUMPER-001`。

**实验状态一直是 PREPARING**

查看主工程接入区域的连接状态和 5199 隔离实例日志。达到启动超时后实验会进入 `FAILED`。

**为什么只能运行一个主工程实验**

主工程隔离实例、虚拟车辆和 PLC 端口属于单套运行环境。其他实验可以通过原生算法并行运行，但同一套主工程虚拟车不能让两个调度器同时控制。
