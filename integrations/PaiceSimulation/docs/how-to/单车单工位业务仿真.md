# 单车单工位业务仿真

本指南用于在排策智演中执行一次主工程九步业务。入口默认选择主工程调度。

<!-- manual -->
1. 在业务场景中选择保存的工程方案，点击“加载方案”。当前隔离实例须已停止。
2. 从方案车辆中选择一辆车，设置合法初始节点，选择一个已绑定 PLC 的 CNC 工位。
3. 点击“开始单次业务”。系统复制方案生成新的隔离实例，仅保留所选车辆，空载、速度倍率 1；地图、PLC 点表及设备绑定继承原方案。保存方案不被覆盖。
4. 后台就绪后发出一次满箱 PLC 呼叫，由主工程自动派车；不创建原生起终点任务集。旧方案的批量呼叫不会执行。
5. 在同页查看九步状态、导航命令、载箱反馈和 PLC 信号。数据过期必须显示，不能将历史反馈当作实时完成证据。
6. 只有实际任务、九步及业务报告闭环才可判定通过；导航到达或写输出成功不能单独作为通过依据。机构反馈仅按虚拟设备实际提供的字段展示，未提供的反馈标为未提供。

请求扩展（兼容原有仅 id 的方案选择/启动请求）：
`POST /api/dispatch/main/simulation/scheme-start`

```json
{"id":"保存方案编号","business":{"vehicleId":"AGV-01","initialSite":"WAIT-01","stationId":"CNC-001"}}
```

business 三项均必填，车辆与工位必须属于所选方案，初始点必须启用且通过原有连通性校验。业务模式不允许载箱起步，默认超时 7200 秒，只生成一个 atSeconds=0、vehicleId=null 的 dispatch-backlog 呼叫。运行中拒绝替换实例；用户须停止当前隔离环境后重新配置。

验收包括：原方案不变、仅一辆车、只呼叫所选工位一次、拒绝未知字段及失效绑定、页面默认主工程、既有原生算法仍可显式选择。随机呼叫及五车测试在本闭环验证后进行。

启动或停止状态仅读取控制器状态，后台运行后才读取任务详情，避免启动期间显示连接拒绝。批量任务与旧实验记录收在可展开的高级区域。
